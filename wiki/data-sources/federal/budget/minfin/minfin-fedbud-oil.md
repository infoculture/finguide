# Минфин: дополнительные нефтегазовые доходы федерального бюджета

| Признак | Значение |
| :--- | :--- |
| Уровень и охват | Помесячный ряд **формирования и использования дополнительных [нефтегазовых доходов](/budget-system/deficit-sources)** федерального бюджета, 2018–2026, в **млрд руб.** |
| Тип доступа | Статическая HTML-страница с одним XLSX; API нет |
| Основные форматы | XLSX, один лист «Информационное сообщение» |
| Оператор и публикатор | [Минфин России](/organizations/minfin) |
| Режим доступа | Открытое скачивание без регистрации |

Коротко: **единственный официальный помесячный ряд механизма дополнительных нефтегазовых доходов** — от НДПИ и экспортной пошлины по видам сырья до расчёта базового объёма, «дополнительных» доходов и покупки/продажи валюты и золота под него. Это расчётная матрица бюджетного правила, а не кассовый реестр: для построчной сверки с исполнением — [формы Казначейства](/data-sources/federal/roskazna-reports), для движения средств [ФНБ](/glossary/nwf) — [отдельная витрина](/data-sources/federal/minfin-fnb-statistics).

## Описание и границы

Карточка описывает страницу [«Информация о дополнительных нефтегазовых доходах федерального бюджета»](https://minfin.gov.ru/ru/statistics/fedbud/oil/) раздела «Статистика → Федеральный бюджет». На странице один документ: «Сведения о формировании и использовании дополнительных нефтегазовых доходов федерального бюджета в 2018-2026 годах» — файл `Svedeniya_202609.xlsx` (суффикс = месяц публикации, путь `/common/upload/library/2026/09/main/`). SHA-256 проверенной копии: `f160def43fcba484f2c3e542829360d59f9ccd0c41dbced1fac526f68c174e48`.

Сюда **не входит**: общий ряд исполнения федерального бюджета — [fedbud/execute](/data-sources/federal/minfin-fedbud-execute) (там нефтегазовые доходы тоже есть, но без расчёта базового объёма и покупок валюты); движение и управление средствами ФНБ — [minfin-fnb-statistics](/data-sources/federal/minfin-fnb-statistics); машиночитаемый реестр — [открытые данные Минфина](/data-sources/federal/minfin-opendata) (этой темы в `list.csv` нет).

## Объекты данных и показатели

Гранулярность — **показатель × месяц**; единицы — **млрд руб.** Состав строк (полный, из проверенного файла):

- **Нефтегазовые доходы, всего**, в том числе:
  - **НДПИ**: нефть, газ, газовый конденсат;
  - **экспортная пошлина**: нефть, газ, нефтепродукты;
  - **акциз на нефтяное сырье** без Кдемп, Кинв и Кврк;
  - **Кдемп, Кинв, Кврк** — демпфирующий, инвестиционный и возвратный коэффициенты (в проверенном файле заполнены не во всех периодах);
  - **НДД** — налог на дополнительный доход.
- **Базовый месячный объём нефтегазовых доходов** — расчётная величина бюджетного правила (прогнозные объёмы добычи/переработки/экспорта по прогнозу СЭР — сноска `***`).
- **Дополнительные нефтегазовые доходы** = факт сверх базового объёма; возможны отрицательные значения (проверено: −182,2 млрд руб. в январе 2026).
- **Объём покупки (продажи) иностранной валюты и золота** — с разбивкой «за счёт разности ожидаемого и базового месячного объёмов» и «за счёт корректировки оценки за предыдущий месяц»; покупки золота отражаются с июля 2021 года (сноска `**`).
- **Справочно**: корректировка оценки дополнительных НГД за предыдущий месяц без равномерного распределения НДД.

Ключи связки: месяц + показатель; для сверки с [исполнением](/data-sources/federal/minfin-fedbud-execute) — строки «Нефтегазовые доходы, всего» и НДПИ на уровне агрегатов; с [ФНБ](/glossary/nwf) — через логику [289-ФЗ](/legal/nwf-289fz), не построчно.

## Структура файлов и словарь данных

Лист «Информационное сообщение», 35 × 114. Шапка: строка 1 — заголовок сообщения; строка 4 — «Показатели» и заголовки периодов; строка 5 — номера колонок (1, 2, 3…); данные с строки 6.

**Ключевая особенность разметки периодов**: 105 колонок с datetime-заголовками (2018-01 … 2026-09) **плюс 8 годовых колонок с целочисленными заголовками** (2018…2025), вставленных после декабря каждого года. Годовая колонка — сумма 12 месячных (проверено: 2018 = 9 017,8 млрд руб. — сумма месячных). Парсер, собирающий «все колонки как месяцы», исказит ряд.

Вторая особенность: **колонка текущего месяца присутствует в шапке, но значения в ней появляются позже** (в файле от 03.09.2026 колонка 2026-09 пуста). Не путайте пустую заготовку с нулём.

| Ловушка | Проявление | Обход |
| --- | --- | --- |
| Годовые колонки | заголовок-число `2018` после декабрьской колонки; сумма 12 месяцев | фильтруйте колонки по `isinstance(datetime)`, годовые обрабатывайте отдельно |
| Заготовка текущего месяца | колонка 2026-09 в шапке без значений | пропускайте колонки без значений, фиксируйте дату файла |
| Строки-заглушки «−» | Кдемп/Кинв/Кврк/НДД содержат текстовый `−` в ранних периодах | приводите к `null`, не к нулю |
| Отрицательные значения | дополнительные НГД и покупки валюты бывают отрицательными | не обрезайте знак |
| Сноски | `*`…`****` в названиях строк | см. легенду ниже |

**Легенда сносок** (подвал файла): `*` — фактическое возмещение акциза по кассовой отчётности Казначейства не совпадает с начисленным (часть компаний обращается за возмещением в последующие периоды); `**` — окно операций покупки/продажи валюты: с пятого рабочего дня текущего месяца по четвёртый (включительно) рабочего дня следующего; золото — с июля 2021; `***` — для расчёта базового объёма используются прогнозные объёмы добычи, переработки и экспорта по прогнозу социально-экономического развития; `****` — корректировка за предыдущий месяц, прогнозный и базовый объём НДД равномерно распределяется в текущем квартале.

## Периодичность обновления

Ежемесячно: файл с колонкой очередного месяца публикуется в первые дни месяца (наблюдение: 03.09.2026). Прямой URL меняется вместе с суффиксом имени файла; пайплайн перечитывает HTML страницы, сверяет дату «Изменено» и SHA-256. Прежние месячные версии файла не хранятся — историю ряда надо копить у себя.

## Ограничения и особенности

- Автоматический доступ к minfin.gov.ru нестабилен из скриптов (в этой среде сессии обрывались; браузероподобный `User-Agent` обязателен).
- Это **расчётная витрина бюджетного правила**: «дополнительные НГД» и покупки валюты — оценки по методике сообщения, а не кассовый факт; не сверяйте их построчно с исполнением по [КБК](/glossary/kbk).
- Методика менялась за 2018–2026 (состав коэффициентов, НДД, золото с 2021) — при длинных рядах учитывайте историчность отдельных строк: часть строк в ранних периодах заполнена заглушками.
- Значения крайних месяцев могут уточняться в следующем файле — фиксируйте версию (дату «Изменено» и хеш).

## Примеры доступа

Скачивание и разбор с разделением месячных и годовых колонок (проверено в этой среде 2026-10-03):

```bash
curl -A "Mozilla/5.0" -o oil.xlsx \
  "https://minfin.gov.ru/common/upload/library/2026/09/main/Svedeniya_202609.xlsx"
```

```python
import re, subprocess, urllib.parse
from datetime import datetime

import openpyxl

page = subprocess.run(
    ["curl", "-s", "-A", "Mozilla/5.0", "https://minfin.gov.ru/ru/statistics/fedbud/oil/"],
    capture_output=True, text=True, check=True).stdout
href = next(h for h in re.findall(r'href="([^"]+\.xlsx)"', page))
url = "https://minfin.gov.ru" + urllib.parse.quote(href)
open("oil.xlsx", "wb").write(
    subprocess.run(["curl", "-s", "-A", "Mozilla/5.0", url], capture_output=True, check=True).stdout)

wb = openpyxl.load_workbook("oil.xlsx", data_only=True)
ws = wb["Информационное сообщение"]
HDR = 4
monthly, annual = {}, {}
for c in range(2, ws.max_column + 1):
    v = ws.cell(row=HDR, column=c).value
    if isinstance(v, datetime):
        monthly[v.strftime("%Y-%m")] = c
    elif isinstance(v, int) and v >= 2018:
        annual[v] = c

def series(row_number, cols):
    return {p: ws.cell(row=row_number, column=c).value for p, c in cols.items()}

r = next(r for r in range(5, ws.max_row + 1)
         if str(ws.cell(row=r, column=1).value or "").startswith("Дополнительные нефтегазовые доходы"))
print("доп. НГД 2026:", series(r, {k: c for k, c in monthly.items() if k.startswith("2026")}))
```

## Частые вопросы

**В: Что такое «базовый месячный объём» и почему «дополнительные» доходы бывают отрицательными?**

**О:** Базовый объём — расчётная планка бюджетного правила из прогнозных объёмов добычи, переработки и экспорта (сноска `***`). Факт сверх планки — дополнительные НГД; если фактические доходы ниже планки, значение отрицательное (проверено: −182,2 млрд руб. в январе 2026). Отрицательными бывают и покупки/продажи валюты — направление операции меняется.

**В: Почему в файле есть пустая колонка за текущий месяц?**

**О:** Файл публикуется в первые дни месяца, и колонка нового месяца уже размечена в шапке, но значения заполняются по мере закрытия периода. Пропускайте пустые колонки — это заготовка, а не ноль.

**В: Как отличить месячные колонки от годовых?**

**О:** По типу заголовка в четвёртой строке: месяцы — datetime (2018-01-01…), годы — целое число (2018…2025), вставленное после декабрьской колонки. Годовая колонка равна сумме 12 месячных (проверено на 2018 годе: 9 017,8 млрд руб.).

**В: Где правовая основа механизма?**

**О:** Формирование и использование дополнительных нефтегазовых доходов и порядок операций с валютой/золотом регулируются [289-ФЗ](/legal/nwf-289fz) и НПА бюджетного правила; конкретные сноски методики — в подвале самого файла.
