# Минфин: краткая информация об исполнении бюджетов государственных внебюджетных фондов

| Признак | Значение |
| :--- | :--- |
| Уровень и охват | Макроряд исполнения **бюджетов [ГВФ](/glossary/extrabudgetary-funds)** в **млрд руб.**: консолидированный блок фондов плюс развилка по СФР, ФОМС и упразднённым ПФР/ФСС |
| Тип доступа | Статическая HTML-страница с тремя XLSX («месяц», «квартал», «год»); API нет |
| Основные форматы | XLSX, по одному листу на файл |
| Оператор и публикатор | [Минфин России](/organizations/minfin) |
| Режим доступа | Открытое скачивание без регистрации |

Коротко: **единственная макровитрина, где динамика [доходов и расходов фондов](/reporting/extrabudgetary-funds-reporting) видна одним рядом с 2011 года**, включая переходный 2023-й: строки Пенсионного фонда и ФСС завершаются декабрём 2022-го, строки СФР начинаются январём 2023-го. Пять показателей на фонд (доходы, в т.ч. страховые взносы, расходы, дефицит/профицит) — быстро и просто; для построчного [КБК](/glossary/kbk) используйте [формы Казначейства по ГВФ](/data-sources/federal/roskazna-extrabudgetary-funds-execution).

| Файл (шаблон имени) | Лист | Приложение | Периоды (фактические данные) | Объём |
| --- | --- | --- | --- | --- |
| `Prilozhenie_9_dannye_117-120_—_mes.xlsx` | `месяц` | 9.3 | 01.2014 — 08.2026 | 39 × 190 |
| `Prilozhenie_9_dannye_117-120_—_kvartal.xlsx` | `квартал` | 9.2 | 1 кв. 2013 — 2 кв. 2026 | 35 × 56 |

Контрольные суммы проверенных копий: месяц — `c1976465e83c55cd123184cc4f3a9f7b36c0df861cde4e088edeb28c964ddf75`, квартал — `5efa86abc4e903b0f21eb2fa2bfb64d2a6c70d14c9abc00d3c406f3c9c8044f7`, год — `fcf2cdf95ad450eecbba2f6dc4844563b50177320ee4582050d268f4d9031aea`.

## Объекты данных и показатели

Гранулярность — **показатель × период × фонд**. Блоки строк (из проверенного месячного файла):

| Блок | Показатели |
| --- | --- |
| 1. Государственные внебюджетные фонды (консолидированно) | доходы, в т.ч. страховые взносы; расходы; дефицит (−)/профицит (+) |
| 2. Фонд пенсионного и социального страхования РФ (**с 2023**) | те же пять показателей |
| 3. Пенсионный фонд РФ (**до 2022**) | те же пять показателей |
| 4. Федеральный фонд обязательного медицинского страхования | те же пять показателей |
| 5. Фонд социального страхования РФ (**до 2022**) | те же пять показателей |

Строки ПФР и ФСС **сохранены в файлах после их упразднения**: данные заканчиваются декабрём 2022 года, а строки СФР начинаются январём 2023-го — [реформа 2023 года](/glossary/extrabudgetary-funds) прямо видна в структуре ряда. Никакой пометки «фонд упразднён» нет: пустые ячейки — единственный признак.

Единицы — **млрд руб.**, значения хранятся как float с длинными хвостами (`1764.43633488747`) — приводите к `Decimal`. Знак минус — дефицит фонда.

Ключи связки: `показатель (номер иерархии) + фонд (номер блока) + период`; для сверки с формами Казначейства — только на уровне одноимённых агрегатов.

## Структура файлов и словарь данных

Шапка: строка 1 — «Приложение 9.N», строка 2 — заголовок («Краткая информация об исполнении бюджетов государственных внебюджетных фондов, млрд. руб.»), строка 3 — заголовки периодов, далее блоки фондов. Полезная область — колонки A:B (мета) + периоды.

Проверенная карта покрытия строк (месячный файл):

| Строка | Показатель | Первое значение | Последнее значение |
| --- | --- | --- | --- |
| 1.1 | Доходы ГВФ (конс.) | 2014-01 | авг. 2026 |
| 2.1 | Доходы СФР | 2023-01 | авг. 2026 |
| 3.1 | Доходы ПФР | 2014-01 | **2022-12** |
| 4.1 | Доходы ФОМС | 2014-01 | авг. 2026 |
| 5.1 | Доходы ФСС | 2014-01 | **2022-12** |

(расходы — те же диапазоны). В квартальном файле аналогично: консолидированный ряд с 1 кв. 2013, ПФР/ФСС до 4 кв. 2022, СФР с 1 кв. 2023; в годовом — с 2011 года.

| Ловушка | Проявление | Обход |
| --- | --- | --- |
| Заголовок шире данных | шапка месячного файла начинается с 01.2011, значения — с 01.2014 | считайте фактическую первую непустую колонку каждой строки, не шапку |
| Строки фондов разной валидности | ПФР/ФСС обрываются 2022, СФР начинается 2023 | при агрегации фильтруйте по периодам, не суммируйте «столбец целиком» |
| Звёздочки в заголовках и названиях | `авг.26*`, `…страхования РФ **` | легенда качества (см. ниже), вырезайте при парсинге |
| float-хвосты | `1764.43633488747` | `Decimal(str(v))`, округление на выходе |
| Отрицательные значения | дефициты фондов | не обрезайте знак |

**Легенда звёздочек** (подвал месячного файла): `*` — **предварительные данные**; `**` — в январе и феврале 2023 данные представлены **на кассовой основе, без учёта зачётов ЕНС** (пометка стоит на строках СФР и ФСС); `***` — данные с учётом информации ФНС о зачётах в счёт налогов, зачисляемых в бюджеты ГВФ, в рамках механизма **ЕНС**. Аналитически важно: стык 2022→2023 — это одновременно смена состава фондов, переход на ЕНС и смена основы учёта; сопоставлять «ПФР+ФСС+ФОМС» до 2023 и «СФР+ФОМС» после напрямую нельзя без оговорок.

## Периодичность обновления

Месячный файл — после закрытия месяца (наблюдаемый лаг ~5 недель); квартальный — отдельно, через ~6 недель после квартала; годовой — после закрытия года (~4 месяца). Прямые URL файлов меняются при каждом обновлении; пайплайн перечитывает HTML страницы, сверяет даты «Изменено» карточек и контрольные суммы.

## Ограничения и особенности

- Автоматический доступ к minfin.gov.ru нестабилен из скриптов (в этой среде сессии обрывались; браузероподобный `User-Agent` обязателен) — закладывайте повторы и проверку SHA-256.
- Имя файла с длинным тире «—» требует URL-кодирования.
- Данные крайних месяцев — предварительные (`*`); фиксируйте версию файла (дату «Изменено» и хеш) вместе со значениями.
- Квартальный файл этой витрины обновляется независимо от месячного (12.08 против 10.09 в проверенной паре) — не предполагайте синхронность, как на [fedbud/execute](/data-sources/federal/minfin-fedbud-execute).
- Показатели не обязаны построчно совпадать с [формами исполнения ГВФ Казначейства](/data-sources/federal/roskazna-extrabudgetary-funds-execution) и срезами [ГИИС «Электронный бюджет»](/data-sources/federal/budget-gov-ru-datasets) — сверяйте методику и момент среза.

## Примеры доступа

Скачивание и разбор месячного файла с учётом границ валидности строк (проверено в этой среде 2026-10-03):

```bash
curl -A "Mozilla/5.0" -o mes.xlsx \
  "https://minfin.gov.ru/common/upload/library/2026/09/main/Prilozhenie_9_dannye_117-120_%E2%80%94_mes.xlsx"
```

```python
import re, subprocess, urllib.parse
from datetime import datetime

import openpyxl

page = subprocess.run(
    ["curl", "-s", "-A", "Mozilla/5.0", "https://minfin.gov.ru/ru/statistics/outbud/execute/"],
    capture_output=True, text=True, check=True).stdout
href = next(h for h in re.findall(r'href="([^"]+\.xlsx)"', page) if "mes" in h)
url = "https://minfin.gov.ru" + urllib.parse.quote(href)
blob = subprocess.run(["curl", "-s", "-A", "Mozilla/5.0", url], capture_output=True, check=True).stdout
open("mes.xlsx", "wb").write(blob)

wb = openpyxl.load_workbook("mes.xlsx", data_only=True)
ws = wb["месяц"]
hdr = next(r for r in range(1, 8)
           if ws.cell(row=r, column=2).value and "Показатель" in str(ws.cell(row=r, column=2).value))
fmt = lambda v: v.strftime("%Y-%m") if isinstance(v, datetime) else str(v)

def series(row_number):
    """Значения строки с фактическими границами: игнорируем пустые колонки."""
    cols = [c for c in range(3, ws.max_column + 1) if ws.cell(row=row_number, column=c).value not in (None, "")]
    return {fmt(ws.cell(row=hdr, column=c).value).rstrip("* "): ws.cell(row=row_number, column=c).value
            for c in cols}

for r in range(hdr + 1, ws.max_row + 1):
    name = str(ws.cell(row=r, column=2).value or "").strip()
    if name.startswith(("Государственные внебюджетные", "Фонд пенсионного", "Пенсионный фонд",
                        "Федеральный фонд", "Фонд социального")):
        continue                                   # заголовки блоков без данных
    if name == "Доходы":
        print(r, name, "->", list(series(r))[:1], "...", list(series(r))[-1:])
```

## Частые вопросы

**В: Почему строка «Пенсионный фонд» обрывается на 2022 году?**

**О:** С 1 января 2023 года ПФР и ФСС объединены в Фонд пенсионного и социального страхования (СФР). В файлах строки ПФР и ФСС сохранены с историческими данными до декабря 2022, строки СФР начинаются с января 2023. Суммируйте ряды с учётом этой границы, а не «по столбцу целиком».

**В: Можно ли корректно сравнить доходы ГВФ за 2022 и 2023 годы?**

**О:** С оговорками: меняются одновременно состав фондов (ПФР+ФСС → СФР), основа учёта в первых месяцах 2023-го (кассовая, без зачётов ЕНС — пометка `**`) и механизм зачётов (пометка `***`). Для сопоставимости берите консолидированный блок «Государственные внебюджетные фонды» и сверяйте пометки легенды в конкретных месяцах.

**В: Почему в шапке месячного файла периоды с 2011 года, а значения начинаются с 2014-го?**

**О:** Макет заголовка шире фактического покрытия данных (проверено: первый непустой месячный показатель — январь 2014). Парсер должен определять границы ряда по значениям, а не по шапке.

**В: Где план по фондам для расчёта процента исполнения?**
