# Минфин: краткая информация об исполнении федерального бюджета

| Признак | Значение |
| :--- | :--- |
| Уровень и охват | Макроряд исполнения **федерального бюджета** в **млрд руб.**: доходы (с нефтегазовой развилкой), расходы по разделам БК, дефицит/профицит, источники финансирования |
| Тип доступа | Статическая HTML-страница с тремя XLSX («месяц», «квартал», «год»); API нет |
| Основные форматы | XLSX, по одному листу на файл |
| Оператор и публикатор | [Минфин России](/organizations/minfin) |
| Режим доступа | Открытое скачивание без регистрации |

Коротко: лучший источник для **быстрого макроряда** по федеральному бюджету — один месячный файл закрывает 2011–2026 годы по 40+ агрегированным показателям, включая [ненефтегазовый дефицит](/budget-system/federal-budget) и детали источников финансирования. Для построчного анализа по [КБК](/glossary/kbk) и регламентированных форм он не предназначен — это контур [Казначейства](/data-sources/federal/roskazna-federal-budget-execution).

## Описание и границы

Карточка описывает страницу [«Краткая информация об исполнении федерального бюджета»](https://minfin.gov.ru/ru/statistics/fedbud/execute/) раздела «Статистика → Федеральный бюджет». На странице ровно три документа:

| Файл (шаблон имени) | Лист | Приложение | Периоды | Объём |
| --- | --- | --- | --- | --- |
| `Prilozhenie_3_dannye_109-111_—_mes.xlsx` | `месяц` | 3.3 | 01.2011 — 08.2026 | 58 × 190 |
| `Prilozhenie_3_dannye_109-111_—_kvartal.xlsx` | `квартал` | 3.2 | 1 кв. 2011 — 2 кв. 2026 | 57 × 64 |
| `Prilozhenie_3_dannye_109-111_—_god.xlsx` | `год` | 3.1 | 2006 — 2025 | 62 × 22 |

Контрольные суммы проверенных копий: месяц — `c808581b202b6622bb9216d337e3194d5d9fa8ac03b2dd3394c3fcf43ecd09c5`, квартал — `0aeb927b58d4227cc6d4cd5a88542068c2ae55e503d880040e9c26c32dceae16`, год — `45c4e9e7941649cb2cb45f983de9e4496cb79b8e8f2a302db8521800d72ea6f7`.

**Согласованность трёх рядов** (проверено численно): квартальные значения — это месячные значения **накопительно с начала года** на март/июнь/сентябрь/декабрь (например, доходы 2 кв. 2011 = 5306,37 = значение на 01.06.2011); годовой файл продолжает месячный ряд в прошлое (доходы 2011 = 11 367,65 = декабрь месячного ряда). Загружать все три файла для одного периода избыточно — достаточно месячного, а годовой нужен только для 2006–2010.

Сюда **не входит**: детализация по КБК, ГРБС и целевым статьям; плановые назначения (закон и роспись); консолидированные бюджеты — зеркальные страницы [conbud](/data-sources/federal/minfin-conbud-execute), [subbud](/data-sources/federal/minfin-subbud-execute), [outbud](/data-sources/federal/minfin-outbud-execute); открытые наборы — [каталог Минфина](/data-sources/federal/minfin-opendata).

## Объекты данных и показатели

Гранулярность — **показатель × период**; строка задаётся номером иерархии (`1`, `1.1.`, `1.2.1.1.`) и названием. Состав разделов (полный, из проверенного месячного файла):

- **РАЗДЕЛ I. Доходы**: всего; **нефтегазовые**; ненефтегазовые — связанные с внутренним производством (НДС внутренний, акцизы, налог на прибыль, НДФЛ), связанные с импортом (НДС на ввозимые, акцизы на ввозимые, ввозные пошлины), прочие.
- **РАЗДЕЛ II. Расходы**: всего и по 14 разделам бюджетной классификации (общегосударственные вопросы, национальная оборона, национальная безопасность, национальная экономика, ЖКХ, охрана окружающей среды, образование, культура и кинематография, здравоохранение, социальная политика, физкультура и спорт, СМИ, обслуживание долга, межбюджетные трансферты общего характера).
- **РАЗДЕЛ III. Дефицит (−)/Профицит (+)** и **ненефтегазовый дефицит**.
- **РАЗДЕЛ IV. Источники финансирования**: внутренние (сальдо внутреннего долга с привлечением/погашением, бюджетные кредиты, приватизация, курсовая разница, изменение остатков, прочее) и внешние (привлечение, погашение, другие).

Единицы — **млрд руб.**, значения хранятся как float с длинными хвостами (`804.8582643055`) — приводите к `Decimal` и округляйте только на выходе. Знак минус — погашение/возврат в разделе IV.

Ключи связки: `показатель (номер иерархии) + период`; для сверки с казначейскими формами — только на уровне одноимённых агрегатов («Доходы, всего», раздел расходов).

## Структура файлов и словарь данных

Шапка одинакова: строка 1 — «Приложение 3.N», строка 2 — заголовок с единицами («Краткая информация об исполнении федерального бюджета (млрд руб.)»; в квартальном добавлено «накопительным итогом»), строка 3 — заголовки периодов (в годовом файле колонок «№ п/п \| Показатель» нет — годы начинаются сразу), далее «РАЗДЕЛ …» и строки данных. Полезная область — колонки A:B (мета) + периоды.

| Ловушка | Проявление | Обход |
| --- | --- | --- |
| Заголовки периодов неоднородны | в месячном файле смешаны datetime (`2011-01-01`) и строки (`авг.26 **`); в квартальном — `1кв.2026` без пробела и `2 кв.2026 **` с пробелом | нормализуйте строковые заголовки регулярным выражением, datetime приводите к дате среза |
| Звёздочки в заголовках и названиях строк | `авг.26 **`, `НДС на ввозимые товары ****` | это легенда качества (см. ниже), вырезайте при парсинге периода |
| float-хвосты | `804.8582643055` млрд руб. | `Decimal(str(v))`, округление на выходе |
| Отрицательные значения | раздел IV, дефицит | не обрезайте знак |

**Легенда звёздочек** (полный текст в строке 56 месячного файла): `*` — государственные (муниципальные) ценные бумаги с номиналом в валюте РФ; `**` — **предварительные данные** (помечают последние месяцы и кварталы); `***` — данные с учётом информации ФНС о зачётах в счёт налогов в рамках механизма **ЕНС**; `****` — с учётом сумм на КБК «Обеспечительный платеж (СПОТ)». Аналитически важно: соседние месяцы могут отличаться методикой учёта зачётов — при сравнении крайних месяцев ряда с более старыми сверяйте пометки.

## Периодичность обновления

Месячный и квартальный файлы обновляются совместно (обе даты «Изменено» совпали: 10.09.2026 при данных на август), годовой — после закрытия года (05.05.2026 за 2025-й). Наблюдаемый лаг месячного — около пяти недель. Прямые URL файлов меняются при каждом обновлении — пайплайн должен перечитывать HTML страницы и сравнивать даты «Изменено» и контрольные суммы.

## Ограничения и особенности

- Автоматический доступ к minfin.gov.ru нестабилен из скриптов (в этой среде сессии обрывались; браузероподобный `User-Agent` обязателен) — закладывайте повторы и проверку SHA-256.
- Имя файла с длинным тире «—» требует URL-кодирования; документируйте кодировку в пайплайне.
- Данные крайних месяцев — предварительные (`**`) и уточняются в следующих публикациях; фиксируйте версию файла (дату «Изменено» и хеш) вместе со значениями.
- Значения не обязаны построчно совпадать с казначейскими формами (другая методика свёртки и момент среза) и с наборами [«Электронного бюджета»](/data-sources/federal/budget-gov-ru-datasets).
- Месячная история начинается с 2011 года: для 2006–2010 доступен только годовой шаг.

## Примеры доступа

Скачивание и разбор месячного файла (проверено в этой среде 2026-10-03):

```bash
curl -A "Mozilla/5.0" -o mes.xlsx \
  "https://minfin.gov.ru/common/upload/library/2026/09/main/Prilozhenie_3_dannye_109-111_%E2%80%94_mes.xlsx"
```

```python
import re, subprocess, urllib.parse
from decimal import Decimal

import openpyxl

page = subprocess.run(
    ["curl", "-s", "-A", "Mozilla/5.0", "https://minfin.gov.ru/ru/statistics/fedbud/execute/"],
    capture_output=True, text=True, check=True).stdout
href = next(h for h in re.findall(r'href="([^"]+\.xlsx)"', page) if "mes" in h)
url = "https://minfin.gov.ru" + urllib.parse.quote(href)          # кодирует и тире, и кириллицу
blob = subprocess.run(["curl", "-s", "-A", "Mozilla/5.0", url], capture_output=True, check=True).stdout
open("mes.xlsx", "wb").write(blob)

wb = openpyxl.load_workbook("mes.xlsx", data_only=True)
ws = wb["месяц"]
header_row = next(r for r in range(1, 8)
                  if ws.cell(row=r, column=2).value and "Показатель" in str(ws.cell(row=r, column=2).value))
periods = {}
for c in range(3, ws.max_column + 1):
    v = ws.cell(row=header_row, column=c).value
    text = (v.strftime("%Y-%m") if hasattr(v, "strftime") else str(v))
    periods[c] = re.sub(r"\s*[*]+$", "", text).strip()             # срезаем звёздочки
for r in ws.iter_rows(min_row=header_row + 1):
    name = str(r[1].value or "").strip()
    if name == "Доходы, всего":
        values = {periods[c.cell.column]: Decimal(str(c.value)) for c in r[2:] if c.value is not None}
        print(sorted(values)[-3:])   # последние месяцы ряда
```

## Частые вопросы

**В: Зачем три файла, если квартальные и годовые значения выводятся из месячного?**

**О:** Исторически так оформлена публикация; численно ряды согласованы (проверено). Практический минимум — месячный файл; годовой добавляет 2006–2010 годы. Квартальный удобен только тем, кто читает таблицы в терминах кварталов.

**В: Почему крайние месяцы помечены `**` и могут меняться?**

**О:** Это предварительные данные по легенде самого файла; кроме того, часть месяцев помечена `***` (учёт зачётов ЕНС) и строки ввозных статей — `****` (обеспечительный платёж СПОТ). При повторной загрузке сверяйте не только дату «Изменено», но и хеш файла.

**В: Можно ли сопоставить строку «Национальная оборона» с формой 0507011 Казначейства?**

**О:** Только на уровне агрегата раздела БК: в казначейской форме тот же раздел детализирован по подразделам, ЦСР и ВР, а значения могут отличаться на момент среза и методику. Сверяйте заголовки и даты обоих источников.

**В: Где план для этих рядов?**

**О:** На этой странице планов нет. Утверждённые назначения — в законах о федеральном бюджете и сводной росписи, машиночитаемые плановые срезы — в [ГИИС «Электронный бюджет»](/data-sources/federal/budget-gov-ru-datasets).
