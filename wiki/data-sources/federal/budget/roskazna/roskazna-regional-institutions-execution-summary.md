# Казначейство: сводная информация по бюджетным и автономным учреждениям субъектов РФ (местных бюджетов)

| Признак | Значение |
| :--- | :--- |
| Уровень и охват | Сводная [отчётность бюджетных и автономных учреждений](/reporting/institution-financial-statements) всех субъектов РФ и муниципалитетов: федеральная витрина, данные — регионального и местного уровня |
| Тип доступа | HTML-каталог с двумя фильтрами (тип, год) и скачиваемыми ZIP; API не опубликован |
| Основные форматы | ZIP с XLS (BIFF8) внутри; в одном месте архива встречается 7z (октябрь 2025) |
| Оператор и публикатор | [Федеральное казначейство](/organizations/federal-treasury) (составитель сводов — финансовые органы субъектов) |
| Режим доступа | Открытый каталог; прямые адреса вложений не являются постоянными endpoint'ами |

Коротко: единственный централизованный публичный источник, где исполнение [ПФХД](/reporting/pfhd) бюджетных и автономных учреждений регионов и муниципалитетов видно в сопоставимом виде по всей стране: квартальные своды формы 0503737 и годовой комплект 0503737 + 0503721 + 0503730 в разрезе субъектов, кодов финансового обеспечения и итога по РФ. Гранулярность — **строка формы × субъект × КФО**, не отдельное учреждение; микроданные учреждений — на [bus.gov.ru](/data-sources/federal/bus-opendata).

## Описание и границы

Карточка описывает подраздел [«Сводная информация по бюджетным и автономным учреждениям субъектов РФ (местных бюджетов)»](https://roskazna.gov.ru/ispolnenie-byudzhetov/svodnaya-informaciya-po-byudzhetnym-i-avtonomnym-uchrezhdeniyam-subuektov-rf-mestnyh-byudzhetov/) раздела «Исполнение бюджетов». В URL оператора — опечатка «sub**ue**ktov» (не «субъектов»); она каноническая, не «чините» её в ссылках.

Интерфейс на дату проверки: тип публикации «Квартальный» (`filter_type=53`) или «Годовой» (`filter_type=54`) и селектор года 2014–2026. GET-параметры Livewire-компонента работают как обычный query string — архив получается без эмуляции браузера.

- **Квартальный** пакет: свод формы **0503737** (исполнение ПФХД по обязательствам) на 1 апреля, 1 июля, 1 октября.
- **Годовой** пакет: комплект форм **0503737**, **0503721** (финансовые результаты) и **0503730** (баланс) на 1 января следующего года; поквартальный фильтр на 01.01 не публикуется.

Сюда **не** входит: своды по федеральным учреждениям — соседний подраздел (см. [параллельную карточку](/data-sources/federal/roskazna-federal-institutions-execution-summary)); исполнение бюджетов субъектов как таковое — [консолидированные бюджеты](/data-sources/federal/roskazna-consolidated-subjects-execution); отчётность отдельного учреждения — [bus.gov.ru](/information-systems/federal/bus-gov).

## Оператор

[Федеральное казначейство](/organizations/federal-treasury) публикует своды; в шапке каждого сводного файла: ГРБС — Министерство финансов РФ, орган, ответственный за составление, — Федеральное казначейство. Первичные своды по субъектам составляют финансовые органы субъектов РФ.

- [Портал Федерального казначейства](/information-systems/federal/roskazna-portal) — витрина, на которой размещён раздел.

## Объекты данных и показатели

- Гранулярность — **строка формы × субъект × вид финансового обеспечения**, где «строка формы» — иерархическая статья доходов/расходов/источников с кодом строки (010, 030, 040…) и кодом аналитики (120, 130, 400…).
- Форма 0503737 в разрезе пяти [видов финансового обеспечения](/glossary/institution-types): собственные доходы (**КФО 2**), субсидия на [госзадание](/glossary/state-assignment) (**КФО 4**), субсидии на иные цели (**КФО 5**), субсидии на капвложения (**КФО 6**), средства ОМС (**КФО 7**). КФО 1 (бюджетные ассигнования) отсутствует — это отчётность БУ/АУ, а не казённых учреждений.
- Меры: «Утверждено плановых назначений» (план ПФХД) и «Исполнено» — в квартальном пакете с разбивкой способа исполнения (через лицевые счета, банковские счета, кассу учреждения, некассовыми операциями), в своде по РФ — по видам КФО; плюс «Сумма отклонения».
- Разделы формы 0503737: 1. Доходы учреждения; 2. Расходы учреждения; 3. Источники финансирования дефицита средств учреждения; 4. Сведения о возвратах остатков субсидий и расходов прошлых лет.
- Значения — рубли с копейками, ОКЕИ 383; встречаются отрицательные (прочие доходы, возвраты).
- Ключи связки: код строки + код аналитики (внутри формы), субъект (код в имени файла и в шапке), отчётная дата, КФО (файл). Для сопоставления с бюджетом субъекта — [консолидированные бюджеты](/data-sources/federal/roskazna-consolidated-subjects-execution) по ОКТМО/субъекту.

Проверенный пример: свод по РФ на 01.01.2026, строка 010 «Доходы — всего»: утверждено 14 694 007 865 335,89 руб.; исполнено итого 14 319 121 716 683,36 руб., в том числе собственные доходы 1 466 385 828 345,96, госзадание 7 134 360 134 716,41, иные цели 2 095 610 797 234,72, капвложения 188 826 611 846,24, ОМС 3 433 938 344 540,03.

**Пробелы**: нет уровня учреждений и муниципалитетов (только субъект); нет отдельного справочника кодов регионов; плановая детализация только итогом по строке.

## Структура файлов и словарь данных

### Годовой ZIP (проверен на 01.01.2026)

15 членов трёх видов:

1. `ФО свод сводов ф. 0503737 на 01.01.2026.zip` — **вложенный ZIP** с 92 XLS: файл `00_FO_…` — итог по РФ, остальные `NN_FO_…` — по субъектам. Это «сводная информация об исполнении учреждением плана ФХД (по субъектам РФ)»: колонки — наименование, код строки, код аналитики, утверждено, исполнено по пяти видам финобеспечения, итого; лист `1`, 189×10, скрытый `XDO_METADATA`.
2. Пять `ФО свод ф. 0503737 … КФО {2,4,5,6,7}.XLS` — та же форма по РФ в разрезе одного КФО (лист `0503737`), плюс годовые своды `ФО свод ф. 0503721 …XLS` (260 строк; колонки по видам деятельности: с целевыми средствами / по госзаданию / приносящая доход / итого) и `ФО свод ф. 0503730 …XLS` (баланс, листы `стр.1_4` и `стр.5_7`; только годовой пакет).
3. Вложенные ZIP `ФО ф. 0503737 на 01.01.2026 КФО N.zip` — по 89 XLS `NN_01.01.2026_0503737.XLS` на субъект (в квартальном пакете 2026 года — 88); аналогичные `ФО ф. 0503721 …zip` и `ФО ф. 0503730 …zip` только в годовом пакете.

### Квартальный ZIP (проверен на 01.07.2026)

11 членов: тот же `ФО свод сводов ф. 0503737 на 01.07.2026.zip`, пять `ФО свод ф. 0503737 на 01.07.2026 КФО N.XLS` и пять вложенных `ФО ф. 0503737 … КФО N.zip`. Формы 0503721 и 0503730 поквартально не публикуются.

### Файл по субъекту (например, `01_01.01.2026_0503737.XLS`, КФО 4)

Шапка: «Учреждение» — финансовый орган субъекта, составивший свод (в проверенном файле — Министерство финансов Республики Башкортостан, ОКПО 00067754, ОКТМО 80000000); «Вид финансового обеспечения (деятельности)» — текстовое название КФО («субсидии на выполнение государственного (муниципального) задания»); периодичность, рубли, ОКЕИ 383. Лист `0503737`, физический размер 220×38 при ~10 содержательных колонках.

| Нормализованное поле | Колонка | Тип | Значение |
| --- | --- | --- | --- |
| `indicator_name` | A | string | Статья доходов/расходов или итог |
| `line_code` | B | code, 3 знака | `010`, `030`, `200`; хранить строкой |
| `analytics_code` | C | code | `120`, `130`, `400`; в ячейках встречается float-вид `120.0` |
| `approved_plan_rub` | D | decimal | Утверждено плановых назначений |
| `executed_treasury_accounts_rub` | E | decimal | Исполнено через лицевые счета |
| `executed_bank_accounts_rub` | F | decimal | Через банковские счета |
| `executed_cash_rub` | G | decimal | Через кассу учреждения |
| `executed_noncash_rub` | H | decimal | Некассовыми операциями |
| `executed_total_rub` | I | decimal | Итого исполнено |
| `deviation_rub` | J | decimal | Сумма отклонения = план − исполнение |

### Коды регионов в именах файлов

Двузначный префикс — код субъекта из ведомственного справочника Казначейства; он **не** совпадает ни с ОКАТО, ни с конституционной нумерацией (01 = Республика Башкортостан, 83 = Луганская Народная Республика, 84 = Ненецкий АО, 87 = ХМАО — Югра, 97 = Херсонская область по проверенным шапкам). Надёжное соответствие — поле «Код региона и наименование субъекта Российской Федерации» в строке 8 шапки каждого файла. В «своде сводов» 92 файла (91 субъект + `00` — итог по РФ); в покомпонентных ZIP по КФО файлов чуть меньше — 89 в проверенном годовом и 88 в квартальном пакете (без `00`, без ЛНР и Херсонской области; состав субъектов между пакетами может отличаться на один — сверяйте список перед склейкой ряда).

## Периодичность обновления

Календарь не публикуется. Режим — три квартальных среза (01.04, 01.07, 01.10) и один годовой (01.01 следующего года). Наблюдаемые лаги: 1,5–2,5 месяца для квартальных, ~5 месяцев для годовых; прецедент заднего числа — кварталы 2014 года, выложенные в феврале 2015-го. Загрузчик должен опрашивать оба фильтра и сравнивать контрольные суммы.

## Ограничения и особенности

- **Двойная вложенность ZIP** и русские имена членов без UTF-8-флага: Python `zipfile` показывает CP437-кракозябры; читаемое имя даёт перекодировка CP437 → CP866 (та же ловушка, что у [ZIP форм федерального бюджета](/data-sources/federal/roskazna-federal-budget-execution)).
- Файл за октябрь 2025 опубликован как **7z** (`FO_0503737-na-01.10.2025.7z`) — единственное отклонение от ZIP в проверенных годах; загрузчик должен уметь оба формата.
- Крупные файлы: у проверенного квартального ZIP скачивание по HTTP/2 оборвалось на ~20 МБ ошибкой `PROTOCOL_ERROR`; повтор по `--http1.1` прошёл полностью. Проверяйте целостность `testzip()` и контрольную сумму.
- BIFF8/XLS требует `xlrd`; `openpyxl` не подходит. В книгах есть скрытый `XDO_METADATA`, многострочные шапки, строки-номера колонок (`1.0 | 2.0 | 3.0`), маркеры страниц «Форма 0503737 с.2» и «х» вместо кодов в итогах — исключайте их при разборе.
- Код аналитики приходит float-подобным (`120.0`) — нормализуйте к строке без `.0`.
- «Утверждено плановых назначений» в по-КФО файлах — одна колонка на весь файл, она не разбита по способам исполнения.
- Опечатка «subuektov» в каноническом URL: при смене адреса ссылка сломается — сохраняйте снимок каталога и имена файлов с датой доступа.
- Состав лет 2014–2026 проверен выборочно; макеты ранних лет могут отличаться (в 2014 не хватает среза на 01.04).

## Примеры доступа

Скачивание годового пакета и чтение свода по РФ с обходом двойного ZIP и CP866:

```bash
  "https://roskazna.gov.ru/storage/page-files/21117/%D0%A4%D0%9E_01.01.2026.zip"
```

```python
import re, html, subprocess, zipfile

def display_names(z):
    return {i: (i.filename if i.flag_bits & 0x800 else i.filename.encode("cp437").decode("cp866"))

with zipfile.ZipFile("annual.zip") as outer:          # уровень 1
    names = display_names(outer)
    inner_info = next(i for i, n in names.items() if n.startswith("ФО свод сводов"))
    with zipfile.ZipFile(BytesIO(outer.read(inner_info))) as svod:   # уровень 2

ws = wb.sheet_by_name("1")   # данные; XDO_METADATA пропускаем
for r in range(ws.nrows):
```

## Частые вопросы

**В: Чем этот раздел отличается от свода по федеральным учреждениям?**

**О:** Охватом: здесь бюджетные и автономные учреждения субъектов РФ и муниципалитетов, чью сводную отчётность составляют финансовые органы регионов. Федеральные БУ/АУ публикуются соседним подразделом с тем же макетом файлов.

**В: Почему в файлах по субъекту «Учреждение» — минфин региона, а не сами учреждения?**

**О:** Файл — свод форма 0503737 по всем БУ/АУ субъекта для одного КФО; финансовый орган как составитель указан в шапке. Данные по отдельным учреждениям ищите на bus.gov.ru.

**В: Как сопоставить код в имени файла `NN_…` с субъектом?**

**О:** Только по шапке файла: строка «Код региона и наименование субъекта Российской Федерации» содержит код и название (например, `87   Ханты-Мансийский автономный округ - Югра`). Нумерация ведомственная и не совпадает с ОКАТО/ОКТМО; `00` — итог по РФ.

**В: Где план и отклонения?**

**О:** В самой форме: колонки «Утверждено плановых назначений» и «Сумма отклонения» рядом с исполнением. Поквартальной детализации плана нет — только нарастающим итогом к дате среза.

**В: Почему нет данных на 1 января в квартальном фильтре?**

**О:** Годовой срез закрывает годовой пакет (там же формы 0503721 и 0503730, которых в квартальных нет). Квартальный фильтр содержит только срезы на 01.04, 01.07 и 01.10.
