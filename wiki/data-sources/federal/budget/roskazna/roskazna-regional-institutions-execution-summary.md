# Казначейство: сводная информация по бюджетным и автономным учреждениям субъектов РФ (местных бюджетов)

| Признак | Значение |
| :--- | :--- |
| Уровень и охват | Сводная [отчётность бюджетных и автономных учреждений](/reporting/institution-financial-statements) всех субъектов РФ и муниципалитетов: федеральная витрина, данные — регионального и местного уровня |
| Тип доступа | HTML-каталог с двумя фильтрами (тип, год) и скачиваемыми ZIP; API не опубликован |

Коротко: централизованный публичный источник сводов исполнения [ПФХД](/reporting/pfhd) бюджетных и автономных учреждений регионов и муниципалитетов: квартальная форма 0503737 и годовой комплект 0503737 + 0503721 + 0503730 по территориям и РФ. Форма 0503737 представлена по КФО, финансовые результаты и баланс — по укрупнённым группам деятельности. Строки отдельных учреждений в проверенных пакетах не выделены; микроданные учреждений — на [bus.gov.ru](/data-sources/federal/bus-opendata).

## Описание и границы

Карточка описывает подраздел [«Сводная информация по бюджетным и автономным учреждениям субъектов РФ (местных бюджетов)»](https://roskazna.gov.ru/ispolnenie-byudzhetov/svodnaya-informaciya-po-byudzhetnym-i-avtonomnym-uchrezhdeniyam-subuektov-rf-mestnyh-byudzhetov/) раздела «Исполнение бюджетов». В URL оператора — опечатка «sub**ue**ktov» (не «субъектов»); она каноническая, не «чините» её в ссылках.

Интерфейс на дату проверки: тип публикации «Квартальный» (`filter_type=53`) или «Годовой» (`filter_type=54`) и селектор года 2014–2026. GET-параметры Livewire-компонента работают как обычный query string — архив получается без эмуляции браузера.

- **Квартальный** пакет: свод формы **0503737** (исполнение ПФХД по обязательствам) на 1 апреля, 1 июля, 1 октября.
- **Годовой** пакет: комплект форм **0503737**, **0503721** (финансовые результаты) и **0503730** (баланс) на 1 января следующего года; поквартальный фильтр на 01.01 не публикуется.

Сюда **не** входит: своды по федеральным учреждениям — соседний подраздел (см. [параллельную карточку](/data-sources/federal/roskazna-federal-institutions-execution-summary)); исполнение бюджетов субъектов как таковое — [консолидированные бюджеты](/data-sources/federal/roskazna-consolidated-subjects-execution); отчётность отдельного учреждения — [bus.gov.ru](/information-systems/federal/bus-gov).

## Оператор

[Федеральное казначейство](/organizations/federal-treasury) публикует своды. В 363 проверенных матрицах «свода сводов» в строках 6–7 названы Министерство финансов РФ и орган, ответственный за составление отчётности, — Федеральное казначейство. В покомпонентных файлах составитель указан в поле «Учреждение»; это финансовый орган территории, а не отдельное БУ/АУ.

- [Портал Федерального казначейства](/information-systems/federal/roskazna-portal) — витрина, на которой размещён раздел.

## Объекты данных и показатели

- Гранулярность — **строка формы × субъект × вид финансового обеспечения**, где «строка формы» — иерархическая статья доходов/расходов/источников с кодом строки (010, 030, 040…) и кодом аналитики (120, 130, 400…).
- Форма 0503737 в разрезе пяти [видов финансового обеспечения](/glossary/institution-types): собственные доходы (**КФО 2**), субсидия на [госзадание](/glossary/state-assignment) (**КФО 4**), субсидии на иные цели (**КФО 5**), субсидии на капвложения (**КФО 6**), средства ОМС (**КФО 7**). КФО 1 (бюджетные ассигнования) отсутствует — это отчётность БУ/АУ, а не казённых учреждений.

Календарь не публикуется. Режим — три квартальных среза (01.04, 01.07, 01.10) и один годовой (01.01 следующего года). Наблюдаемые лаги: 1,5–2,5 месяца для квартальных, ~5 месяцев для годовых; прецедент заднего числа — кварталы 2014 года, выложенные в феврале 2015-го. ## Ограничения и особенности

- **Двойная вложенность ZIP** и русские имена членов без UTF-8-флага: Python `zipfile` показывает CP437-кракозябры; читаемое имя даёт перекодировка CP437 → CP866 (та же ловушка, что у [ZIP форм федерального бюджета](/data-sources/federal/roskazna-federal-budget-execution)).
- Файл за октябрь 2025 опубликован как **7z** (`FO_0503737-na-01.10.2025.7z`) — единственное отклонение от ZIP в проверенных годах; загрузчик должен уметь оба формата.
- Все пять пакетов скачаны с `--http1.1`; прежнее сообщение об обрыве HTTP/2 в этой проверке не воспроизводилось. Целостность ZIP проверена на обоих уровнях, 7z — командой `7zz t`; SHA-256 записан в манифест.
- Все 2 888 XLS — BIFF8; у каждого есть скрытый `XDO_METADATA`. Пропускайте лист метаданных, повторные шапки, строки-номера колонок и маркеры страниц. Строки с `х`/`x` или пустым кодом сохраняйте: среди них есть итоги и финансовые статьи.
- Код аналитики приходит float-подобным (`120.0`) — нормализуйте к строке без `.0`.
- «Утверждено плановых назначений» в по-КФО файлах — одна колонка на весь файл, она не разбита по способам исполнения.
- Опечатка «subuektov» в каноническом URL: при смене адреса ссылка сломается — сохраняйте снимок каталога и имена файлов с датой доступа.
- Макеты срезов на 01.07.2014 и 01.01.2019 вскрыты и описаны отдельно. Внутреннее устройство остальных ранних пакетов не проверялось; наличие ссылки в каталоге не доказывает совместимость макета.

## Примеры доступа

Следующий пример проверен на скачанном годовом пакете 2026-11-03 (Python 3.12.14, xlrd 2.0.2). Используется явный исследовательский обход ошибки цепочки TLS этой среды; при рабочей цепочке исключите `--insecure`.

```bash
curl --http1.1 --insecure --fail --location -A "Mozilla/5.0" \
  --output annual.zip \
  "https://roskazna.gov.ru/storage/page-files/21117/%D0%A4%D0%9E_01.01.2026.zip"
```

```python
from decimal import Decimal
from io import BytesIO
import hashlib
import zipfile
import xlrd

def decoded(info):
    return (info.filename if info.flag_bits & 0x800 else
            info.filename.encode("cp437").decode("cp866"))

payload = open("annual.zip", "rb").read()
assert hashlib.sha256(payload).hexdigest() == (
    "0f1283a5f4b75fe71f25b0f8b8a3183c6e6775cc5fe93cd417d842488c38e7bf"
)
with zipfile.ZipFile(BytesIO(payload)) as outer:
    assert outer.testzip() is None
    member = next(i for i in outer.infolist()
                  if decoded(i).startswith("ФО свод сводов"))
    with zipfile.ZipFile(BytesIO(outer.read(member))) as inner:
        assert inner.testzip() is None
        rf = next(i for i in inner.infolist() if decoded(i).startswith("00_"))
        book = xlrd.open_workbook(file_contents=inner.read(rf))
sheet = book.sheet_by_name("1")
for r in range(sheet.nrows):
    if str(sheet.cell_value(r, 1)).strip() == "010":
        assert Decimal(str(sheet.cell_value(r, 9))) == Decimal("14319121716683.36")
        print(sheet.row_values(r)[:10])
```

## Частые вопросы

**В: Чем этот раздел отличается от свода по федеральным учреждениям?**

**О:** Охватом: здесь бюджетные и автономные учреждения субъектов РФ и муниципалитетов, чью сводную отчётность составляют финансовые органы регионов. Федеральные БУ/АУ публикуются соседним подразделом с тем же макетом файлов.

**В: Почему в файлах по субъекту «Учреждение» — минфин региона, а не сами учреждения?**

**О:** Файл — свод форма 0503737 по всем БУ/АУ субъекта для одного КФО; финансовый орган как составитель указан в шапке. Данные по отдельным учреждениям ищите на bus.gov.ru.

**В: Как сопоставить код в имени файла `NN_…` с субъектом?**

**О:** В матрицах «свода сводов» код и название находятся в B8 (например, `87   Ханты-Мансийский автономный округ - Югра`). В покомпонентных файлах 2026 года этой строки нет: используйте датированный справочник из матриц и ОКПО составителя для балансов без префикса. Нумерация ведомственная; `00` — итог по РФ. В справочник также входят «Сириус» и Байконур.

**В: Где план и отклонения?**

**О:** В самой форме: колонки «Утверждено плановых назначений» и «Сумма отклонения» рядом с исполнением. Поквартальной детализации плана нет — только нарастающим итогом к дате среза.

**В: Почему нет данных на 1 января в квартальном фильтре?**

**О:** Годовой срез закрывает годовой пакет (там же формы 0503721 и 0503730, которых в квартальных нет). Квартальный фильтр содержит только срезы на 01.04, 01.07 и 01.10.
