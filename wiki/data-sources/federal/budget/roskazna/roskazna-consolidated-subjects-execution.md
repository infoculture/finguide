# Казначейство: консолидированные бюджеты субъектов РФ и бюджетов территориальных государственных внебюджетных фондов

| Признак | Значение |
| :--- | :--- |
| Уровень и охват | Исполнение [консолидированных бюджетов субъектов РФ](/glossary/consolidated-budget) и бюджетов территориальных ГВФ: форма 0503317 ежемесячно и годовой комплект 0503317+0503320+0503321+0503323 |
| Тип доступа | HTML-каталог с двумя фильтрами (тип, год) и скачиваемыми ZIP объёмом ~58–89 МБ; API не опубликован |
| Основные форматы | ZIP с вложенными ZIP; внутри BIFF8/XLS, HTML (CP1251) и XLSX под расширением `.xls` |
| Оператор и публикатор | [Федеральное казначейство](/organizations/federal-treasury); первичные своды составляют финансовые органы субъектов |
| Режим доступа | Открытый каталог; прямые адреса вложений не являются постоянными endpoint'ами |

Коротко: главный источник для межрегионального анализа бюджетов субъектов и муниципалитетов — официальная [форма 0503317](/reporting/0503317) по каждой территории с раскладкой «бюджет субъекта / все типы муниципальных бюджетов / бюджет ТГВФ» и «суммами, подлежащими исключению» двойного счёта, плюс единственное место, где на месячном срезе виден итог по РФ и федеральным округам (сводная «шахматка» «по графам»). Муниципальная детализация — именно здесь, а не в региональных публикациях; микроданных учреждений нет (см. [свод по учреждениям](/data-sources/federal/roskazna-regional-institutions-execution-summary)).

## Описание и границы

Карточка описывает подраздел [«Консолидированные бюджеты субъектов РФ и бюджетов территориальных государственных внебюджетных фондов»](https://roskazna.gov.ru/ispolnenie-byudzhetov/konsolidirovannye-byudzhety-subektov-rossijskoj-federacii/) раздела «Исполнение бюджетов». В URL оператора — «sub**e**ktov» без второй «с»; это каноническое написание, не ошибка копирования.

Интерфейс на дату проверки: тип «Ежемесячный» (`filter_type=48`) или «Годовой» (`filter_type=49`) и селектор года **2000–2026**; GET-параметры Livewire-компонента работают как query string.

- **Ежемесячный** пакет `КБСРФ на 01.ММ.ГГГГ.zip` — форма 0503317 по 92 территориям в трёх представлениях (см. «Структура файлов»).
- **Годовой** пакет `КБСРФ на 01.01.ГГГГ_год.zip` — то же плюс три годовые формы: **0503320** (баланс исполнения консолидированного бюджета), **0503321** (консолидированный отчёт о финансовых результатах), **0503323** (консолидированный отчёт о движении денежных средств).

Сюда **не** входит: консолидированный бюджет РФ и бюджеты федеральных ГВФ — [соседний раздел](/data-sources/federal/roskazna-consolidated-rf-and-ebf-execution); исполнение федерального бюджета — [формы 0503117/0507011](/data-sources/federal/roskazna-federal-budget-execution); своды по учреждениям — [отдельный подраздел](/data-sources/federal/roskazna-regional-institutions-execution-summary); макро-XLSX Минфина по субъектам — [subbud/execute](/data-sources/federal/minfin-subbud-execute).

## Объекты данных и показатели

- Гранулярность — **строка формы × территория × уровень бюджета**. Форма 0503317 содержит разделы: 1. Доходы бюджета; 2. Расходы бюджета; 3. Источники финансирования дефицита; 4. Таблица консолидируемых расчётов (поступления/выбытия между уровнями: субсидии, субвенции, дотации — строки 899–930).
- Двухуровневая шапка мер: пары «консолидированный бюджет субъекта и ТГВФ» + «суммы, подлежащие исключению в рамках консолидации», затем развилки по уровням: **бюджет субъекта**, бюджеты внутригородских муниципальных образований, муниципальных округов, городских округов, городских округов с внутригородским делением, внутригородских районов, муниципальных районов, городских поселений, сельских поселений, **бюджет ТГВФ**; в каждой группе — утверждённые назначения и исполнение.
- Коды — сегментированные [КБК](/glossary/kbk): в расходах отдельными колонками раздел/подраздел (4), целевая статья (10), вид расходов (3); «х» — маркер итога, не код.
- Годовые формы: 0503320 — баланс по строкам актива/пассива на начало и конец года в той же развилке уровней; 0503321 — финансовые результаты по [КОСГУ](/glossary/kosgu); 0503323 — поступления/выбытия денежных средств по КОСГУ.
- Значения — рубли с копейками; встречаются отрицательные (источники, исключаемые суммы).
- Ключи связки: `территория (код) + form_code + report_date + line_code + сегменты КБК + уровень бюджета`. Итог по РФ и федеральным округам на месячном срезе — только из «шахматки» (см. ниже).

Проверенные примеры: Башкортостан, 0503317 на 01.08.2026, строка 200 «Расходы бюджета — всего»: 532 023 698 218,57 руб. назначений консолидированного бюджета; «шахматка» доходов на ту же дату: Российская Федерация — 17 782 252 496 742,42 руб.

**Пробелы**: нет сводного XLS по РФ (только «шахматка» с укрупнёнными группами КБК); нет отдельного справочника территорий вне HTML; нет планов на будущие периоды; муниципальная развилка — только по типам МО, не по конкретным муниципалитетам.

## Структура файлов и словарь данных

### Месячный пакет (проверен на 01.08.2026)

Три вложенных ZIP:

1. **`ф. 0503317_01.08.2026_по ФО+Свод Excel .zip`** — 92 XLS `NN_01.08.2026_0503317.XLS` по территориям. Листы: `XDO_METADATA` (скрытый), `0503317_Д` (доходы, ~1023×36), `0503317_Р` (расходы, ~1613×40), `0503317_ИФ` (источники, 88×36), `0503317_Табл` (консолидируемые расчёты, 135×14). Файла с итогом по РФ (`00_…`) в архиве **нет**, хотя «Свод» обещан именем. BIFF8, рубли, «Периодичность: Месячная».
2. **`ф. 0503317_01.08.2026_по ФО_месячная_html.zip`** — 94 файла: `style.css`, `ReportsCatalog.html`, `TerrList_428m.html` (**каталог территорий: код → наименование**) и 92 файла `Mes_428m_NN.html` — та же форма в HTML (кодировка **CP1251**). Итога по РФ нет.
3. **`Доходы_расходы_источники по графам на 01.08.2026.zip`** — 36 книг (3 раздела × 12 файлов): сводные «шахматки», где строки — укрупнённые группы КБК с составными кодами (например, `01000010000000000000000` «Доходы бюджета — ИТОГО»), строки-территории «0 — Российская Федерация», «1–8 — федеральные округа» и все субъекты; 8 листов по округам. **Книги — XLSX, хотя расширение `.xls`** — `xlrd` их отвергает, нужен `openpyxl`.

### Годовой пакет (проверен на 01.01.2026)

Шесть вложенных ZIP: три месячных представления плюс:

- **`ф. 0503320_на 01.01.2026_Сводный + в разрезе субъектов РФ.zip`** — 92 XLS; листы `стр.1_8_Баланс`, `стр.9_12_Справка`, `стр.13_Таблица`.
- **`ф. 0503321_…zip`** — 92 XLS; листы `0503321_1` (результаты) и `0503321_2`; колонка кода — КОСГУ.
- **`ф. 0503323_…zip`** — 92 XLS; листы `1` (поступления) и `2` (выбытия) по КОСГУ.

Во всех трёх — та же развилка уровней бюджетов; сводного файла по РФ в архивах нет (и в именах уже не заявлен).

### Коды территорий

Двузначные коды `01–97` — внутренний справочник Казначейства, не совпадающий ни с ОКАТО/ОКТМО, ни с конституционной нумерацией: 01 — Республика Башкортостан, 18 — Краснодарский край, 72 — Санкт-Петербург, 81 — федеральная территория «Сириус», 82 — ДНР, 83 — ЛНР, 84 — Ненецкий АО, 87 — ХМАО — Югра, 96 — город Байконур, 97 — Херсонская область. Каноническое соответствие — файл `TerrList_428m.html` из HTML-архива (или шапка конкретного XLS); не реконструируйте коды по другим классификаторам.

## Периодичность обновления

Календарь не публикуется. Режим — срез на каждое 1-е число (с 2005 года; в 2000-м — квартальный) и годовой срез 1 января. Наблюдаемые лаги: 8 дней — 6 недель для месячных (в 2025 году встречались оба края), ~5 месяцев для годовых. Прецеденты правки задним числом: перезалив 01.12.2010 в декабре 2018 года. Загрузчик должен опрашивать каталог по обоим фильтрам и сравнивать контрольные суммы.

## Ограничения и особенности

- **Три уровня вложенности ZIP** (внешний пакет → представление → «шахматка» с папками) и имена членов CP866 без UTF-8-флага — та же ловушка, что у [архивов федерального бюджета](/data-sources/federal/roskazna-federal-budget-execution).
- **Файлы «по графам» — XLSX с расширением `.xls`**: выбирайте парсер по сигнатуре (`PK`), а не по расширению.
- HTML-набор в CP1251 — декодируйте явно; `Requests`+`.text` с угаданной кодировкой даст кракозябры.
- Большие пакеты: годовой ZIP (89 МБ) в этой среде не скачался за один проход по HTTP/2 (обрыв `PROTOCOL_ERROR`); сработал `--http1.1` с докачкой `-C -`. Всегда проверяйте `testzip()` и SHA-256.
- Итог по РФ на месячном срезе отсутствует в Excel и HTML — только укрупнённая «шахматка»; не собирайте его суммированием субъектов без вычитания консолидируемых расчётов (раздел 4 формы).
- В файле `01_…_0503321` (Башкортостан, проверенный годовой пакет) в шапке указано «Наименование бюджета: **Федеральный бюджет**» — ошибка заполнения источником; ориентируйтесь на финансовый орган в шапке и код в имени файла.
- BIFF8 требует `xlrd`: скрытые `XDO_METADATA`, многострочные шапки, строки-номера граф, «х» в кодовых колонках, физический размер шире содержательной области.
- Фиктивные даты публикаций старых лет (1-е число от старой CMS) — не используйте их как временные метки; в 2010–2015 годах встречаются пачечные выкладки и перезаливы.
- Имена пакетов переключились с латиницы (`KBSRF-na-…`) на кириллицу («КБСРФ на …») между 2025 и 2026 годами — загрузчик должен принимать оба варианта.

## Примеры доступа

Скачивание месячного пакета с докачкой и чтение формы субъекта:

```bash
URL="https://roskazna.gov.ru/storage/page-files/512/%D0%9A%D0%91%D0%A1%D0%A0%D0%A4%20%D0%BD%D0%B0%2001.08.2026.zip"
curl -k --http1.1 -C - -A "Mozilla/5.0" -O "$URL"   # повторять до полного размера, затем проверить SHA-256
```

```python
import zipfile
from io import BytesIO
import xlrd

def display_names(z):
    return {i: (i.filename if i.flag_bits & 0x800 else i.filename.encode("cp437").decode("cp866"))
            for i in z.infolist()}

with zipfile.ZipFile("КБСРФ на 01.08.2026.zip") as outer:                 # уровень 1
    names = display_names(outer)
    excel_info = next(i for i, n in names.items() if "Excel" in n)
    with zipfile.ZipFile(BytesIO(outer.read(excel_info))) as inner:       # уровень 2
        inames = display_names(inner)
        t = next(i for i, n in inames.items() if n.startswith("01_"))    # 01 = Башкортостан
        wb = xlrd.open_workbook(file_contents=inner.read(t))

ws = wb.sheet_by_name("0503317_Р")          # раздел 2 «Расходы бюджета»
for r in range(ws.nrows):
    if str(ws.cell_value(r, 0)).strip().startswith("Расходы бюджета - всего"):
        print("строка 200, конс. бюджет (назначения):", ws.cell_value(r, 3))
        break
```

Для «шахматки» используйте `openpyxl.load_workbook(..., data_only=True)` несмотря на расширение `.xls`. Пример проверен в этой среде 2026-10-03; обход TLS-проверки в `curl -k` — исследовательский.

## История и контекст

Раздел закрывает потребность в едином сопоставимом ряде по региональным и местным бюджетам: форма 0503317 составляется финансовыми органами субъектов, Казначейство сводит их в пакеты «по субъектам» и публикует с 2000-х годов. Эволюция архива видна по именам и датам: до 2015 года — латинские имена (`KBSRF-na-…`) и фиктивные даты старой CMS, затем реальные временные метки, с 2026 года — кириллические имена. Наполнение расширялось: годовые пакеты получили балансы (0503320), финансовые результаты (0503321) и движение денежных средств (0503323), а состав территорий — новые субъекты и федеральную территорию «Сириус». «Шахматка» «по графам» остаётся единственным публичным местом, где месячный итог по РФ и федеральным округам по консолидированным бюджетам субъектов доступен напрямую.

## Частые вопросы

**В: Где в месячном пакете итог по России?**

**О:** В Excel-архиве его нет (файла `00_…` не существует, несмотря на «Свод» в имени). Итог по РФ и федеральным округам на месячном срезе публикуется только в «шахматке» `Доходы_расходы_источники по графам…` — по укрупнённым группам КБК. Не суммируйте субъекты напрямую: межбюджетные потоки исключаются через раздел 4 формы и «суммы, подлежащие исключению».

**В: Почему файлы «по графам» не открываются xlrd?**

**О:** Они XLSX, хотя расширение `.xls`. Определяйте формат по сигнатуре (`PK…` — OOXML) и читайте `openpyxl`; xlrd работает только с настоящим BIFF8 из Excel-архива формы.

**В: Как связать код в имени файла с субъектом?**

**О:** Справочник — `TerrList_428m.html` в HTML-архиве того же пакета (код → наименование для всех 92 территорий, включая «Сириус» и Байконур) либо шапка самого XLS. Нумерация ведомственная: 01 — Башкортостан, а не Адыгея; 72 — Санкт-Петербург.

**В: Чем годовой пакет отличается от месячного за январь?**

**О:** Годовой фильтр (`filter_type=49`) на 1 января содержит не только 0503317, но и 0503320/0503321/0503323, которых в месячных пакетах нет вообще. Месячный фильтр январского среза — это только 0503317.

**В: Как вытащить конкретный муниципалитет?**

**О:** Никак: форма даёт развилку по типам муниципальных образований (городские округа, муниципальные районы, поселения и т.д.) в рамках субъекта. Данные по конкретному МО — в [региональных публикациях](/data-sources/regional/consolidated-budgets).
