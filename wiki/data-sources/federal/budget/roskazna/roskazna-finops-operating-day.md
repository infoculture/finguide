# Казначейство: операционный день (материалы раздела «Финансовые операции»)

| Признак | Значение |
| :--- | :--- |
| Уровень и охват | **Страница удалена.** Прежний охват — ежедневная сводка итогов финансовых операций Казначейства с [ЕКС](/data-sources/federal/roskazna-finops-treasury-account-placements) |

Коротко: страница была **единственным местом портала, где итоги операционного дня по всем инструментам были собраны в одну таблицу** — депозитные аукционы, репо на организованных и неорганизованных торгах, бюджетные кредиты, валютные свопы и депозиты с центральным контрагентом, с суммами, ставками, сроками и остатками к возврату. На октябрь 2026 страница **не существует** (404, из меню «Финансовые операции» пункт исчез); исторические данные доступны в [Wayback Machine](https://web.archive.org/web/2026/https://roskazna.gov.ru/finansovye-operacii/operacionnyj-den), актуальные — на листовых страницах операций и в [витринах данных](/data-sources/federal/roskazna-datamarts).

## Описание и границы

Карточка фиксирует **исчезнувший источник**, чтобы разорванные ссылки и старые выписки из данных не вводили в заблуждение. Прежний URL: `https://roskazna.gov.ru/finansovye-operacii/operacionnyj-den` — пункт меню «Финансовые операции» рядом с листовыми страницами размещения и привлечения средств.

Страница была реализована как Livewire-компонент с полями «дата с / дата по» (`wire:model="dateFrom"`, `wire:model="dateTo"`; в проверенном снимке `max="2026-06-09"`) и **транспонированной таблицей**: колонки — отдельные операции (по датам отбора заявок), строки — атрибуты. Единицы — **миллионы рублей / долларов США / китайских юаней**, а не рубли; ставки — проценты.

Блоки таблицы (полный состав подписей строк из снимка 2026-06-09):

| Блок | Атрибуты |
| --- | --- |
| Размещено на банковских депозитах | сумма (млн руб. / млн долл. США); минимальная ставка в заявках, %; средневзвешенная ставка (фиксированная или спред), %; срок, дней; количество кредитных организаций, заявки которых удовлетворены; остатки к возврату (млн руб. / млн долл. США) |
| Размещено по договорам репо не на организованных торгах | то же плюс суммы и остатки в млн китайских юаней |
| Размещено по договорам репо на организованных торгах | средневзвешенная ставка, %; срок, дней; остаток к возврату, млн руб. |
| Предоставлено бюджетных кредитов | остаток к возврату, млн руб. |
| Остаток на банковских счетах | (строка-агрегат) |
| Размещено по валютным свопам | купленная валюта |
| Размещено на депозитах с центральным контрагентом | средневзвешенная ставка, %; срок, дней; остаток к возврату, млн руб. |

Проверенный пример из снимка 2026-06-09: операция 01.06.2026 «размещено на банковских депозитах» — 628 000,0 млн руб., минимальная ставка 13,85%, срок 2 дня, заявки 3 кредитных организаций удовлетворены.

Сюда **не входило**: регламентное расписание операционного дня (время приёма документов), [формы исполнения бюджетов](/data-sources/federal/roskazna-federal-budget-execution), почасовые остатки ЕКС.

## Объекты данных и показатели

- Гранулярность — **одна операция размещения/привлечения в колонке таблицы**: `дата отбора × инструмент × атрибут`.
- Меры: сумма размещения (млн руб. / USD / CNY), минимальная и средневзвешенная ставка (%), срок (дней), число кредитных организаций, остаток к возврату (млн руб. / USD / CNY).
- Ключи связки с живыми источниками: дата операции + инструмент ↔ листовые страницы [размещений на банковских депозитах](/data-sources/federal/roskazna-finops-treasury-account-placements) и [привлечения средств](/data-sources/federal/roskazna-finops-treasury-account-fundraishing), где публикуются дневные протоколы отбора заявок (`…otbor_*.docx`).
- Числа локализованы: пробел — разделитель тысяч, запятая — десятичный (например, `628 000,0`).

**Пробелы**: нет выгрузок и API; глубина истории на одном снимке ограничена выборкой фильтра; соответствие итогов таблицы и листовых протоколов формально не описано.

## Периодичность обновления

Неприменимо: страница удалена. При жизни обновлялась по операционным дням (в июньском снимке 2026 года присутствовали операции вплоть до 08.06.2026 при `max` фильтра 09.06.2026).

## Ограничения и особенности

- **Главное ограничение — источник мёртв**: не стройте на нём пайплайны; для текущих данных используйте листовые страницы операций и [витрины](/data-sources/federal/roskazna-datamarts).
- Ссылки на эту страницу из сторонних материалов после июня 2026 года ведут в никуда; канонический способ цитирования истории — снимок Wayback с датой.
- Единицы — **млн**, а не рубли: при стыковке с формами исполнения бюджетов (рубли, ОКЕИ 383) требуется пересчёт ×10⁶; валютные суммы в млн USD и млн CNY — отдельные поля, не конвертация.
- Таблица транспонирована: парсер должен читать колонки как записи, а строки как поля.
- Снимки Wayback не сохраняют работу Livewire-фильтра: данные на снимке — лишь тот диапазон, который был отрисован в момент снятия.

## Примеры доступа

Живой URL для контроля статуса и получение исторического снимка:

```bash
curl -sk -A "Mozilla/5.0" -o /dev/null -w "%{http_code}\n" \
  "https://roskazna.gov.ru/finansovye-operacii/operacionnyj-den"     # 404 на 2026-10-03

curl -sL -o snapshot.html \
  "https://web.archive.org/web/20260609084258/https://roskazna.gov.ru/finansovye-operacii/operacionnyj-den"
```

Разбор транспонированной таблицы снимка (первая строка — даты, первая колонка — атрибуты):

```python
import re, html

raw = open("snapshot.html", encoding="utf-8", errors="replace").read()
table = re.findall(r"<table[^>]*>(.*?)</table>", raw, re.S)[0]
rows = []
for tr in re.findall(r"<tr[^>]*>(.*?)</tr>", table, re.S):
    cells = [" ".join(html.unescape(re.sub(r"<[^>]+>", " ", c)).split())
             for c in re.findall(r"<t[hd][^>]*>(.*?)</t[hd]>", tr, re.S)]
    rows.append([c for c in cells if c])

dates = rows[0][1:]            # колонки-операции
for row in rows[1:]:
    if row[0].startswith("Размещено на банковских"):
        print("инструмент: депозиты; дат:", len(dates))
    elif row[0].startswith("Сумма, млн рублей"):
        for date, value in zip(dates, row[1:]):
            print(date, "->", value.replace(" ", "").replace(",", "."))
```

Пример проверен на снимке 2026-06-09 в этой среде 2026-10-03.

## История и контекст

Страница существовала минимум с августа 2020 года (первый снимок Wayback) и пережила редизайн портала: в снимках и 2024, и 2026 годов — один и тот же Livewire-компонент с фильтром дат и та же структура транспонированной таблицы. Между 09.06.2026 (последний снимок с данными) и 03.10.2026 (проверка, 404) пункт «Операционный день» был убран из меню «Финансовые операции»; раздел теперь содержит только листовые страницы размещений/привлечения, календарь, архив и технический раздел. Сама дневная информация не исчезла: протоколы отбора заявок продолжают публиковаться на листовых страницах (DOCX вида `02.10.2026otbor_14.docx`), а сводные ряды — в витринах данных. Для задач, где нужна именно историческая агрегированная таблица операционного дня, остаётся Wayback Machine.

## Частые вопросы

**В: Страница не открывается — это временный сбой?**

**О:** Нет. На 2026-10-03 URL отдаёт 404, пункт удалён из меню раздела, поиск по порталу результатов не даёт, а последний снимок Wayback с данными датирован 09.06.2026. Рассчитывайте на снимки веб-архива или на живые листовые страницы операций.

**В: Где теперь взять те же показатели — суммы, ставки, остатки по депозитам и репо за день?**

**О:** По инструментам — на листовых страницах: [размещение средств ЕКС](/data-sources/federal/roskazna-finops-treasury-account-placements) (депозиты, репо, ПФИ, ЦК) и [привлечение на ЕКС](/data-sources/federal/roskazna-finops-treasury-account-fundraishing); там публикуются дневные протоколы DOCX. Машиночитаемые ряды — в [витринах данных](/data-sources/federal/roskazna-datamarts).

**В: Можно ли восстановить историю показателей из Wayback?**

**О:** Частично: каждый снимок содержит только диапазон дат, отрисованный на момент снятия, и снимки нерегулярны. Для систематического ряда лучше использовать листовые страницы и витрины; Wayback пригоден для точечных дат и контроля методики.

**В: Почему суммы «странные» — например, 628 000,0?**

**О:** Единицы таблицы — миллионы (рублей, долларов США, юаней), а запятая — десятичный разделитель. 628 000,0 млн руб. = 628 млрд руб. При стыковке с бюджетными формами в рублях нужен пересчёт.
