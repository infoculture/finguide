# Отчёты Федерального казначейства (исполнение бюджетов)

| Признак | Значение |
| :--- | :--- |
| Уровень и охват | Хаб-раздел «Исполнение бюджетов» портала Казначейства: **девять подразделов** — от регламентированных форм федерального бюджета до иллюстрированного издания |
| Тип доступа | Страница раздела — чистая навигация; каждый подраздел — каталог Livewire с фильтрами типа и года и скачиваемыми файлами; API нет |
| Основные форматы | ZIP → XLS/XLSX в подавляющем большинстве подразделов; PDF — в иллюстрированном издании; отдельные исторические DOCX/XLS |
| Оператор и публикатор | [Федеральное казначейство](/organizations/federal-treasury) |
| Режим доступа | Открытый; прямые адреса вложений не являются постоянными endpoint'ами |

Коротко: это вход в **казначейский факт** об исполнении бюджетов — официальные формы по [КБК](/glossary/kbk) за многие годы в одном разделе. Карточка даёт проверенную карту подразделов (какой подраздел за что отвечает, какие у него фильтры и глубина архива) и отсылает к профильной карточке каждого. Сопоставление с планами и росписью — контур [ГИИС «Электронный бюджет»](/data-sources/federal/budget-gov-ru-datasets), машиночитаемые ряды — [витрины данных](/data-sources/federal/roskazna-datamarts).

Девять подразделов левого меню (состав и URL — на 2026-10-03). «Типы» — значения фильтра периодичности с их числовыми идентификаторами в интерфейсе; «годы» — диапазон селектора.

| Подраздел | Типы публикаций (id) | Годы | Профильная карточка |

| Иллюстрированное информационное издание | без фильтров; 10 годовых PDF (2013–2022; файлы 2013–2016 размещены на minfin.ru) | — | [Издание](/data-sources/federal/roskazna-illustrated-budget-publication) |
| Федеральный бюджет | 43 годовой, 44 квартальный, 45 ежемесячный, 46 оперативный | месячные 1997–2026; квартальные 2010–2026; годовые 2005–2025; оперативные 2010–2022 | [Исполнение ФБ](/data-sources/federal/roskazna-federal-budget-execution) |

| Бюджеты государственных внебюджетных фондов | 48 ежемесячный, 49 годовой | 2010–2026 | [Бюджеты ГВФ](/data-sources/federal/roskazna-extrabudgetary-funds-execution) |

| Сводная информация по федеральным БУ/АУ | 51 годовой, 52 ежемесячный, 55 квартальный; свежие пакеты вида `ГРБС_0503737_01.07.2026.zip` | 2014–2026 | [Свод по федеральным учреждениям](/data-sources/federal/roskazna-federal-institutions-execution-summary) |

| Использование выделяемых бюджетных средств | 47 квартальный (расходы главы 100 «Федеральное казначейство») | 2010–2026 | [Использование средств](/data-sources/federal/roskazna-budget-funds-use) |

Основные формы в разрезе подразделов: федеральный бюджет — 0503117, 0507011, 0507012, 0507019, 0507020, 0507024, 0507060; консолидированные бюджеты субъектов — 0503317 (месяц) и 0503317+0503320+0503321+0503323 (год); своды по учреждениям — 0503737 (+0503721, 0503730 в годовых). Предметные карточки форм: [0503117](/reporting/0503117), [0503317](/reporting/0503317).

Сюда **не входит**: управление ликвидностью (депозиты, репо, календарь размещений) — раздел «Финансовые операции» (см. [размещение средств ЕКС](/data-sources/federal/roskazna-finops-treasury-account-placements)); микроданные учреждений — [bus.gov.ru](/data-sources/federal/bus-opendata); документация ПП № 658 — [отдельная карточка](/data-sources/federal/roskazna-pp658-execution).

## Оператор

[Федеральное казначейство](/organizations/federal-treasury) ведёт раздел и публикует файлы.

- [Портал Федерального казначейства](/information-systems/federal/roskazna-portal) — витрина, на которой размещён раздел.

## URL и точки доступа

| Тип доступа | URL | Формат и назначение |
| --- | --- | --- |
| Раздел «Исполнение бюджетов» | https://roskazna.gov.ru/ispolnenie-byudzhetov/ | HTML, чистая навигация (файлов на странице нет) |
| Подраздел с фильтром | `…/ispolnenie-byudzhetov/<slug>/?filter_type=<id>&filter_year=<год>` | HTML; рабочий способ получить архив без эмуляции браузера |
| Каталог открытых данных | https://roskazna.gov.ru/opendata/ | HTML-каталог наборов Казначейства (серии 7707329152 — ФНС-происхождения, 7710568760 — казначейские) |

Единый механизм выборки во всех подразделах с фильтрами — Livewire-компонент `files-list-with-month-filter`: GET-параметры `filter_type` и `filter_year` принимаются сервером, ответ — готовый HTML со списком карточек и путями `downloadFile('…')`.

**Про числовые id фильтров**: они не документированы оператором, стабильность не гарантирована, а значения **повторяются между подразделами** с одинаковыми подписями (48 «Ежемесячный» работает и в консолидированных контурах, и в статистике). Загрузчик обязан сверять текст выбранного фильтра, а не полагаться только на число.

## Объекты данных и показатели

- Базовая гранулярность всех форм раздела — **строка формы × классификационный код × период**: доходы/расходы/источники по [КБК](/glossary/kbk) (федеральный бюджет, консолидированные контуры) или строка ПФХД × КФО (своды по учреждениям).
- Развилки: уровни бюджетов (в 0503317 — бюджет субъекта, все типы муниципальных, ТГВФ), главный распорядитель (0507012, 0507024), виды финансового обеспечения учреждений.
- Меры: план (назначения, роспись) и кассовое исполнение, в рублях с копейками (казначейские формы — ОКЕИ 383); в «Использовании выделяемых средств» — два агрегата по главе 100.
- Ключи связки между подразделами: `form_code + report_date + КБК (или код строки) + уровень бюджета`; для территорий — код региона из ведомственного справочника Казначейства (не ОКАТО/ОКТМО).

## Периодичность обновления

Календарь оператором не публикуется. Типовой режим: месячные срезы (1-е число), квартальные (1 января/апреля/июля/октября с лагом 1,5–2,5 месяца), годовые (лаг ~5 месяцев). Прецеденты правок задним числом и перезаливов задокументированы в профильных карточках — пайплайн должен опрашивать каталог и сравнивать контрольные суммы.

## Ограничения и особенности

- Проверки HTTPS в этой среде стабильно завершались ошибкой цепочки доверия (`curl` — `SSL certificate problem`); после исследовательского обхода сервер отвечал. В производственном загрузчике используйте корректное хранилище сертификатов.
- Крупные ZIP (24–89 МБ) обрываются по HTTP/2 (`PROTOCOL_ERROR`); надёжен `--http1.1` с докачкой `-C -` — обязательно проверяйте `testzip()` и SHA-256.
- Русские имена членов ZIP записаны без UTF-8-флага: Python `zipfile` показывает CP437-кракозябры; лечится перекодировкой CP437 → CP866. У консолидированных пакетов вложенность ZIP до трёх уровней.
- Даты публикаций старых лет фиктивны (унаследованы от прежней CMS): «1-е число» в карточке ничего не говорит о реальном времени выкладки.
- Канонические URL содержат опечатки оператора («sub**ue**ktov», «sub**e**ktov» в разных подразделах) — не «исправляйте» их в ссылках.
- Побочные форматы-ловушки в отдельных подразделениях: XLSX под расширением `.xls`, 7z вместо ZIP (одна публикация сводов по учреждениям), DOCX-протоколы, файлы на соседнем домене minfin.ru (иллюстрированное издание за 2013–2016).

## Примеры доступа

Универсальный обход подраздела с фильтрами (работает во всех подразделах карты, кроме иллюстрированного издания):

```bash
curl -k -A "Mozilla/5.0" -o section.html \
  "https://roskazna.gov.ru/ispolnenie-byudzhetov/konsolidirovannye-byudzhety-subektov-rossijskoj-federacii/?filter_type=48&filter_year=2026"
```

```python
import re, html, subprocess

BASE = "https://roskazna.gov.ru/ispolnenie-byudzhetov/federalnyj-byudzhet/"
page = subprocess.run(
    ["curl", "-sk", "-A", "Mozilla/5.0", f"{BASE}?filter_type=45&filter_year=2026"],
    capture_output=True, text=True, check=True).stdout
paths = list(dict.fromkeys(html.unescape(p) for p in re.findall(r"downloadFile\('([^']+)'\)", page)))
for p in paths:
    print(p)          # относительные пути вложений; качать с URL-кодированием кириллицы
```

Проверено в этой среде 2026-10-03; обход TLS-проверки в `curl -k` — исследовательский.

## Частые вопросы

**В: Как выбрать подраздел под задачу?**

**О:** Исполнение федерального бюджета — «Федеральный бюджет»; регион с муниципалитетами — «Консолидированные бюджеты субъектов РФ»; страна в целом с ГВФ — «Консолидированный бюджет РФ и бюджетов ГВФ»; только СФР/ФОМС — «Бюджеты ГВФ»; учреждения (ПФХД по КФО) — своды по учреждениям; расходы самого Казначейства — «Использование выделяемых средств»; наглядные годовые итоги — иллюстрированное издание.

**В: Есть ли API, чтобы скачать всё сразу?**

**О:** Нет. Публичный контракт — HTML-каталоги подразделов с GET-параметрами фильтров и файлы по ссылкам; альтернативы для автоматизации — [каталог opendata](https://roskazna.gov.ru/opendata/) и [витрины данных](/data-sources/federal/roskazna-datamarts).

**В: Почему один и тот же `filter_type=48` работает в разных подразделах?**

**О:** Числовые идентификаторы типов публикаций не документированы и не глобальны: 48 — «Ежемесячный» сразу в трёх подразделах, а 51–55 — типы сводов по федеральным учреждениям. Не переносите id между подразделами без сверки текста фильтра на странице.

**В: Чьи даты у карточек файлов — отчётные или публикации?**

**О:** В карточках рядом с файлом портал показывает дату **публикации** (у старых лет — фиктивную, от прежней CMS); отчётная дата зашита в имя файла и в шапку книги. Различайте их при качественном контроле загрузок.
