# Регламентная загрузка: QA-чеклист

Базовая проверенная выборка — 2026-11-03; исходные URL/размеры/хеши в [downloads.json](downloads.json), состав — [members.json](results/members.json). Числовой результат базовой проверки — [qa-summary.json](results/qa-summary.json).

1. **Обновить каталог с сохранением снимков.** `collect.py --catalog --sizes --refresh` запрашивает две ветки шести заданных лет. Для проверки другого года расширить список явно. Сохранять дату публикации и дату среза раздельно; повтор одного URL в двух годах не является новым пакетом. Не строить старый URL из имени файла.
2. **Скачать фактическую ссылку.** `collect.py --url '<URL из каталога>' --refresh` с HTTP/1.1, кодированием кириллицы и User-Agent. В среде с корректной цепочкой TLS не передавать `--insecure`; иначе явно записать исключение. Проверить ненулевой размер, фактический формат по сигнатуре, хеш и известный эталон. При смене копии сохранить прежнее тело/метаданные и сравнить хеши.
3. **Вскрыть все уровни.** `unpack.py` вызывает `testzip()` каждого ZIP и `7zz t` для 7z; неизвестное расширение не трактовать как XLS. Сохранять сырые/читаемые имена, CRC, SHA-256, размер и полный путь. Обнаруженный член `other` требует классификации; пока распознан только `ProtocolFO.txt`.
4. **Проверить покрытие и макет.** `research.py` должен прочитать каждый XLS; нулевое число распознанных строк требует расследования. Сравнить имена листов, поля кодов, шапки и позиции с YAML, а не только nrows. Карта по смыслу колонки/раздела обязательна. Новый год не считается совместимым только по совпадению номера формы.
5. **Проверить состав.** Считать фактические файлы каждого ZIP и уникальные коды; сравнивать с матрицей той же даты/историческим перечнем, а не общим числом 89. Базовые текущие ожидания: матрица 92, годовой КФО 91/89/91/83/89; квартальный 91/88/91/82/89. Различия публикуются в `qa-composition.json`, отсутствие не заполняется нулевыми строками автоматически.
6. **Проверить территории.** `references.py`: B8 матрицы → код/название, шапки компонентов → реквизиты составителя. ОКПО сохраняет ведущие нули; ОКТМО сохраняет наблюдаемую длину. Баланс без кода связывается только при уникальном ОКПО на ту же дату. Все unresolved и конфликты реквизитов требуют отдельного рассмотрения; источник связи сохраняется.
7. **Собрать tidy.** `parse.py` сохраняет физическую координату каждого факта. Проверить `representation`, КФО/группу деятельности, раздел, opening/closing; общий план матрицы не дублировать по КФО. Null отдельно от 0, код 010 строкой, 120.0 → 120, встроенная Х в 41Х сохраняется. Раздел 4 использует собственную карту колонок.
8. **Запустить `qa.py --strict`.** Проверяются SHA всех сохранённых основных скачиваний, покрытие всех XLS профилями, число XLS против протокола, контрольные строки 010/200/450/500/910/950: территории → РФ, КФО → матрица, пять КФО → итог. Горизонтально проверяются способы исполнения и группы деятельности. Расчёты — Decimal с точностью 0,01; ненулевой delta приводит к ошибке strict-запуска. Повреждённый архив / отсутствие профиля / неверный протокол также завершают загрузку ошибкой.
9. **Разобрать статусы без подмены результата.** `pass` — две доступные суммы совпали; `difference` — обе доступны и отличаются; `unavailable` — одна/обе суммы недоступны. В непустом аддитивном наборе blank учитывается как 0 только для контроля. Полностью пустой набор остаётся unavailable. Базовая выборка: 461 pass/10 unavailable межфайловых и 134 186 pass/3 819 unavailable горизонтальных сравнений. Не объявлять unavailable успешной сверкой и не подставлять отсутствующих субъектов.
10. **При расхождении сохранить всё.** Указать пакет, полный член, лист/строку/меру, ожидаемую и фактическую сумму, delta и состав слагаемых. Проверить сдвиг раздела 4, смешение итогов/деталей, состав территорий, десятичную запятую/NBSP, знак и полноту файла. Гипотезу усечения/изменения охвата отделить от установленной причины. Исходные строки не удалять ради прохождения QA.
11. **Проверить регрессии и выпуск.** `test_parser.py -v`; обновить словарь и фрагменты только для проверенных макетов. Зафиксировать границы выборки. При изменении wiki выполнить `npm run lint:frontmatter`, `npm run export:knowledge`, `npm run export:knowledge -- --check`, `npm run lint:related-pages`, `npm run lint:corpus` и сборку; производные экспорты не редактировать вручную.

Скрипты сохраняют доказательства и результаты проверок. Это пример загрузки для документированных пакетов, а не универсальный детектор любых будущих изменений: даже если суммы сошлись, новый макет и изменившийся состав требуют содержательной проверки перед включением в временной ряд. Ранние годовые 0503721/0503730 2014 года не вскрывались; проверенный ранний годовой комплект — за 2018.
