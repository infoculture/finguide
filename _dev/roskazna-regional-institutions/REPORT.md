## Исправленные исходные предположения

1. **A/B и покомпонентный территориальный файл — разные макеты.** Пустой B встречается у реальных расходных статей и не означает удаление строки. Код аналитики используется в разных осях: 400 в доходах — операции с активами, в расходах — капитальные вложения.
2. **Раздел 4 меняет физические колонки.** Плана нет. Матрица: D–H КФО, I итог. Один КФО: D–G способы, H итог. Проверены все 2 128 стандартных/матричных файлов; 2014 имеет только три раздела.
3. **Не все ZIP по КФО содержат 89/88 файлов.** Для годового 2026 по КФО 2/4/5/6/7: **91/89/91/83/89**; квартального: **91/88/91/82/89**. ЛНР/Херсонская область отсутствуют в КФО 4, но присутствуют в КФО 2/5/7. В КФО 7 отсутствуют коды 81/96. Точный состав каждого ZIP и различия — [qa-composition.json](results/qa-composition.json).
4. **91 территориальный файл — не 91 субъект РФ.** В B8 опубликованы в том числе `81 Федеральная территория "Сириус"` и `96 город Байконур`. Свидетели: `ФО свод сводов ф. 0503737 на 01.07.2026.zip!81_FO_01.07.26.XLS` и `…!96_FO_01.07.26.XLS`; проверены все 92 шапки текущего пакета. Территориальные наименования воспроизведены как в источнике, без самостоятельной правовой классификации.
5. **177 территориальных балансов лишены кода в имени.** 91 файл годового 2026 и 86 файлов за 2018: `_дата_0503730[_порядковый_суффикс].XLS`. Суффикс не используется как код территории. Все сопоставлены по уникальному ОКПО на ту же дату. Источник — [region-observations-resolved.json](results/region-observations-resolved.json); неразрешённых случаев нет.
6. **B8 содержит территорию только в матрице.** В покомпонентных 0503737 шапка имеет B5 «Учреждение», J5 ОКПО, J7 ОКТМО, B10 вид деятельности. В матрицах нет ОКПО/ОКТМО составителя; они присоединяются из других файлов.
7. **Историческая совместимость не сводится к имени листа.** За 2018 изменены колонки 0503721/0503730, листы баланса и имена ZIP. В 2014 даже поле с подписью «по ОКПО» содержит территориальные коды `01`/… и код `9500` у свода. Эти значения сохранены отдельно; ОКПО организации из них не выдумывался.
8. **Коды аналитики не всегда числовые.** В 179 файлах 0503721 встречаются буквенные `29T`, `41Х` и др. `Х` внутри кода не тождественна отдельному маркеру `х`.
9. **Суммы бывают текстовыми.** 80 денежных ячеек в 15 книгах содержат строки, в частности с NBSP/запятой. Их разбор проверен; числовые значения не сравниваются как строки.
10. **Путь хранения не универсален.** Старые ссылки используют `/uploads/migrate/...`; фиксированный префикс `/storage/page-files/21117/` подходит только к части текущих вложений. GET-фильтры работают во всех 12 полученных снимках.

## Справочники и числа

[regions.csv](regions.csv) содержит 92 кода последнего среза: 91 территория и 00 с пустым названием в шапке. Идентификаторы — ОКПО/ОКТМО составителя из покомпонентных файлов, а не общие идентификаторы территории из матрицы. Для 83/84/87/97 непосредственно проверены соответственно **5/5/5/4 файла на 01.07.2026**. История содержит 807 сочетаний даты/названия/идентификаторов; конфликтов непустых ОКПО/ОКТМО внутри одной даты/кода не обнаружено. Корректность реквизитов во внешнем реестре не проверялась.

Справочник формы содержит **494 датированных варианта строки/наименования**, с разделом, кодом строки (включая null), аналитикой, признаками итогов и свидетелями. КФО в документации привязаны к наблюдаемым названиям шапок. Иерархия выведена из напечатанных арифметических ссылок; неустановленные уровни оставлены null. Такая производная разметка не объявляется нормативным классификатором.

Итоги [qa-summary.json](results/qa-summary.json):

- **471 межфайловая сверка**: 461 совпадение до копейки, 10 пустых/неприменимых сравнений, ненулевых расхождений нет. Проверены контрольные строки 010/200/450/500/910/950, сумма территорий против РФ, сумма КФО против общего итога, отдельные КФО против матриц, а для 2014 — территориальные КФО против сводов.
- **138 005 горизонтальных проверок**: 134 186 совпадений, 3 819 недоступных сравнений. Ненулевых расхождений нет. Полностью пустой набор не превращался в успешный нулевой контроль.
- На **01.01.2026, строка 010** план равен **14 694 007 865 335,89**, исполнение — **14 319 121 716 683,36 руб.** Все семь эталонных значений из задания совпали. Сумма 91 территориального файла и пяти КФО совпала с итогом РФ.
- На **01.07.2026, строка 010** исполнение равно **7 423 711 544 135,95 руб.**, разность с суммой территорий **0,00**.
- **8 регрессионных тестов прошли.** Отдельно проверены повреждённый ZIP, защищённый путь распаковки, нормализация кодов/сумм, сдвиг раздела 4, пустые коды, исторические колонки, баланс без префикса и текстовый протокол.
- Даты среза из имени и шапки сопоставлены во всех **2 888 XLS**: расхождений нет; [date-validation.json](results/date-validation.json). Шаблоны имён словаря совпали со всеми 2 889 XLS/TXT. Два Python-примера из README и фрагмента wiki выполнены без изменений кода примеров.
- Аудит непрочитанных числовых строк внутри границ финансовых таблиц охватил все 2 888 XLS: непустых числовых мер на пропущенных строках не обнаружено. Его точная область — числовые BIFF-ячейки между первой и последней распознанной строкой, без строк-номеров колонок; [skipped-numeric-rows.json](results/skipped-numeric-rows.json).

Полная tidy-таблица содержит **1 962 763 факта**, без неразрешённых кодов территорий. Это совокупность альтернативных представлений, не набор для безусловного суммирования. Исходные Decimal записаны в CSV текстом с двумя знаками; пусто отдельно от явного нуля. Физическая трассировка — архивная цепочка, лист, строка и колонка. [tidy-summary.json](results/tidy-summary.json) фиксирует размер/хеш результата, [tidy-sample.csv](tidy-sample.csv) содержит небольшую выборку.

| **Не проверено:** все промежуточные годы и все кварталы 2014–2026 | Расширить годы сборщика и выборку; не переносить текущий макет без сканирования. |
| **Не воспроизводилось:** прежний `PROTOCOL_ERROR` HTTP/2 | В этой работе использован только HTTP/1.1. Для проверки отдельно загрузить крупный файл по HTTP/2 и сохранить stderr/код возврата; текущая документация не выдаёт прежнее наблюдение за новое доказательство. |
| **Не установлено:** почему отсутствуют отдельные территориальные файлы КФО | Сопоставить нулевые/пустые показатели матрицы с первичными сводами/разъяснением публикатора. Совпадение сумм не доказывает причину отсутствия. |

| **Не проверено:** нормативная иерархия всех кодов аналитики, их действие по годам | Сверить с редакциями формы/классификаторов отдельно. Текущий справочник даёт значения и смысл только по напечатанным названиям. |
| **Не проверено:** полнота первичной отчётности учреждений и муниципалитетов | Нужна сверка с первичными реестрами; опубликованные своды такой проверки не заменяют. |
| **Наблюдалось однократно:** `ProtocolFO.txt`, CP1251 | Найти протоколы других пакетов и проверить формат до обобщения парсера. |
| **Наблюдалось в этой среде:** ошибка локальной проверки цепочки TLS | Исправить цепочку CA/проверить сервер из другой среды и повторить без `--insecure`. Текущие SHA/CRC не являются доказательством аутентичности TLS-соединения. |

Ненулевых числовых расхождений в проверенных контролях нет, поэтому гипотезы об усечении сумм не подставлялись. Структурные аномалии сохранены отдельно и не удалены из набора. Карточка wiki обновлена четырьмя фрагментами и сопутствующими исправлениями противоречащих им старых утверждений.
