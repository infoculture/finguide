# Казначейство: структуры сводов региональных БУ/АУ

Исследование выполнено **2026-11-03, Europe/Moscow**. Открыты пять пакетов, прочитаны все **2 888 XLS** и один текстовый протокол. Область применимости ограничена этими пакетами; наличие других ссылок в каталоге не означает проверки их содержимого.

Основные результаты:

- [data-dictionary.yaml](data-dictionary.yaml) — 15 вариантов XLS и текстовый протокол; листы, размеры, шапки, объединения, карты колонок по разделам, реальные примеры с координатами, справочники и tidy-схема.
- [wiki-fragments.md](wiki-fragments.md) — четыре готовых раздела карточки. Они также вставлены в существующую карточку без изменения порядка её разделов.
- [REPORT.md](REPORT.md) — объём доказательств, результаты сверок, исправленные предположения и непроверенные вопросы.
- [quirks.md](quirks.md) — упорядоченный чеклист ловушек с файлами-свидетелями.
- [qa-checklist.md](qa-checklist.md) — порядок регламентной загрузки и трактовка статусов.
- [regions.csv](regions.csv) — 92 кода последнего среза; [regions-history.csv](regions-history.csv) — датированные реквизиты и источники.
- [tidy-sample.csv](tidy-sample.csv) — небольшая выборка фактов; полная таблица создаётся локально как `results/tidy.csv` и исключена из Git.

Проверенная среда: **Python 3.12.14**, `xlrd 2.0.2`, `PyYAML 6.0.3`, `beautifulsoup4 4.14.3`, `curl 8.7.1`, `7zz 26.05`. Зависимости Python закреплены в [requirements.txt](requirements.txt). Для BIFF8 используется `xlrd`, не `openpyxl`; исходные книги не изменяются.

## Воспроизведение

Из корня репозитория:

```bash
cd _dev/roskazna-regional-institutions
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python collect.py --insecure --catalog --samples --sizes
.venv/bin/python unpack.py
.venv/bin/python research.py
.venv/bin/python references.py
.venv/bin/python parse.py
.venv/bin/python qa.py --strict
.venv/bin/python test_parser.py -v
.venv/bin/python build_dictionary.py
.venv/bin/python build_docs.py
.venv/bin/python finalize.py
```

`--insecure` — явный обход ошибки цепочки TLS, наблюдавшейся в этой среде. При доступной корректной цепочке запускайте без него. Копии сверены по SHA-256/CRC, но эти проверки не заменяют аутентификацию сервера. Сборщик использует HTTP/1.1, User-Agent `Mozilla/5.0`, URL-кодирование пути и двухсекундные паузы между запросами. Сохранённый файл с совпадающей контрольной суммой берётся из кеша; `--refresh` выполняет новый запрос и сохраняет изменившееся предыдущее тело в `raw/history/<sha256>/`.

Скачивания и распакованные книги находятся в `raw/` и `extracted/` и исключены из Git. [downloads.json](downloads.json) содержит дату доступа, URL, размер, SHA-256 и статус TLS каждого из 17 основных скачиваний. [artifacts-manifest.json](artifacts-manifest.json) дополнительно учитывает сохранённые HTTP-заголовки. [actions.jsonl](actions.jsonl) — журнал действий. Дата доступа члена архива наследуется от внешнего пакета; его собственные размер/CRC/SHA-256 и полный путь находятся в [members.json](results/members.json).

Сборка словаря не требует повторного скачивания. Команда `build_docs.py --apply-wiki` заменяет только четыре именованных раздела существующей карточки; содержательные поправки в остальных разделах сделаны редакционно и этой командой не управляются. После изменения wiki выполните проверки репозитория и `npm run export:knowledge` из его корня.

## Назначение кода

| Файл | Что делает |
| --- | --- |
| `collect.py` | Сохраняет HTML двух GET-фильтров шести лет, извлекает фактические ссылки, скачивает пять свидетелей, измеряет HEAD-размеры остальных вложений. |
| `unpack.py` | Проверяет оба уровня ZIP/7z, восстанавливает CP866-имена, сохраняет полный инвентарь и не допускает выхода пути за папку распаковки. |
| `parse.py` | Читает все варианты BIFF8; выбирает карту по макету/листу/разделу; нормализует коды и Decimal; создаёт CSV фактов. |
| `protocol.py` | Читает единственный наблюдавшийся текстовый протокол CP1251. |
| `research.py` | Проверяет каждый XLS, сохраняет профили, свидетелей, наблюдения реквизитов, строки формы и аномалии. |
| `references.py` | Создаёт датированные справочники; восстанавливает код баланса только по уникальному ОКПО на ту же дату. |
| `qa.py --strict` | Проверяет хеши, покрытие всех XLS, число отчётов протокола, состав территорий, межфайловые и горизонтальные суммы; ненулевое расхождение завершает strict-запуск с ошибкой. |
| `test_parser.py` | Восемь проверок регрессий на реальных скачанных файлах, включая повреждённый ZIP и сдвиг раздела 4. |
| `build_dictionary.py`, `build_docs.py`, `finalize.py` | Собирают словарь/фрагменты из доказательств, манифест сопутствующих файлов и небольшую tidy-выборку. |

Пример разбора отдельного файла без повторного исследования (из этой папки после распаковки):

```python
import json
import xlrd
from collect import ROOT
from parse import rows, tidy

inventory = json.loads((ROOT / "results/members.json").read_text())
member = next(x for x in inventory if x["kind"] == "xls"
              and "01.01.2026 КФО 4.zip!01_" in x["member"])
book = xlrd.open_workbook(ROOT / member["local_path"])
data = list(rows(book, member["member"]))
assert next(r for r in data if r["line_code"] == "910")["source_columns"]["executed_total_rub"] == "H"
facts = [fact for row in data for fact in tidy(row)]
```

Для полного присоединения названий и восстановления кодов балансов используйте CLI `parse.py`: он вызывает датированный resolver. КФО хранится только там, где он определён отдельно. Группы деятельности 0503721/0503730 и общие план/итог матрицы имеют `kfo=null`.

**Не суммируйте всю tidy-таблицу.** В ней повторяются альтернативные представления одних сумм: матрица, отдельный КФО, РФ и территории, итоги и их детализация, а у баланса — начало/конец периода. Надёжный физический ключ: `source_member + sheet + source_row + source_col`. Смысловой ключ требует также формы, раздела, аналитики, КФО/группы деятельности и периода; пустой код строки не удаляется.
